[12:00 – 25:00] التحكم في التدفق: if / else
============================================================

الأداة الأولى: if و else.

if (condition) {
    // كود يُنفَّذ إذا تحقق الشرط
} else {
    // كود يُنفَّذ إذا لم يتحقق
}

مثال بسيط:
const age = 20;
if (age >= 18) {
    console.log('بالغ');
} else {
    console.log('قاصر');
}

الشرط هو أي تعبير يُقيَّم إلى true أو false.
مثل:
- age >= 18
- name === 'سارة'
- isLoggedIn
- count > 0 && count < 10

الآن، الحالة التي عندنا عدة احتمالات:
استخدم else if.

const grade = 85;
if (grade >= 90) {
    console.log('امتياز');
} else if (grade >= 80) {
    console.log('جيد جداً');
} else if (grade >= 70) {
    console.log('جيد');
} else if (grade >= 60) {
    console.log('مقبول');
} else {
    console.log('راسب');
}

انتبهوا لترتيب الشروط.
الأعلى أولاً، ثم الأقل. لأن الشرط الأول الذي يتحقق يُنفَّذ،
والباقي يُتجاهل. لو كتبت العكس، ستحصل على نتائج غريبة.

هناك أيضاً شكل مختصر للشروط البسيطة، وهو ternary:
const msg = age >= 18 ? 'بالغ' : 'قاصر';

هذا سطر واحد فقط، يصلح لحالة بسيطة.
لكن لا تكتب شروطاً متداخلة بـternary.
الكود يصبح صعباً في القراءة، وأنت لا تكسب شيئاً.

============================================================
[25:00 – 35:00] Truthy و Falsy
============================================================

قبل أن نكمل، لا بد أن نتحث عن مفهوم مهم جداً:
Truthy و Falsy.

في JavaScript، عند استخدام قيمة في if،
يتم تحويلها ضمنياً إلى boolean:
- true يبقى true.
- false يبقى false.
- لكن أيضاً: 0، "", null, undefined, NaN
  كلها تعتبر false في الشروط.
- كل ما عدا ذلك true: الأرقام غير الصفر، النصوص غير الفارغة،
  المصفوفات (حتى الفارغة)، الكائنات.

أمثلة تفاجئ المبتدئين:
if ("0") { /* صحيح! لأن النص غير فارغ */ }
if ([]) { /* صحيح! لأن المصفوفة كائن */ }
if ({}) { /* صحيح */ }
if (0) { /* خطأ */ }
if ("") { /* خطأ */ }

لماذا هذا مهم؟ لأن مدخلات النماذج تأتي كنصوص.
إذا استخدمت:
const value = input.value;  // مثلاً "0"
if (value) { /* صحيح! */ }

لكن 0 كرقم يعتبر false. هذا ينتج أخطاء عجيبة.

القاعدة: كن صريحاً في شروطك.
بدل if (value)، اكتب if (value !== '') أو if (Number(value) > 0).
الوضوح أفضل من الاختصار.

============================================================
[35:00 – 45:00] switch
============================================================

لدينا أيضاً switch للمطابقة بقيمة.

switch (day) {
    case 'السبت':
    case 'الأحد':
        console.log('يوم عمل');
        break;
    case 'الجمعة':
        console.log('نهاية الأسبوع');
        break;
    default:
        console.log('قيمة غير معروفة');
}

switch يُقارن بقيمة ثابتة — لا يقبل شروطاً معقدة.
هو أنظف من if / else if عندما تطابق قيمة بقيم ثابتة.
مناسب لأيام الأسبوع، حالات الطلب، أنواع المستخدم، إلخ.

الفرق بين switch وif:
- if يقبل شروطاً معقدة مثل age >= 18 && hasID.
- switch يطابق قيمة بـ ===.
- if أكثر مرونة، switch أنظف لحالة واحدة من مطابقات.

تحذير مهم: لا تنسوا break.
بدون break، ينفّذ البرنامج الحالات التالية حتى يجد break.
هذا يسمى fall-through، ويُستخدم أحياناً في حالات متعمدة،
لكنه في الغالب خطأ.

مثال متعمد على fall-through:
case 'السبت':
case 'الأحد':   // هذا مقصود: كلاهما نفس المعالجة
    console.log('بداية الأسبوع');
    break;

============================================================
[45:00 – 60:00] الحلقات: for
============================================================

الآن الحلقات. هدفها تكرار كود.

for (let i = 0; i < 5; i++) {
    console.log('التكرار', i);
}

البنية ثلاثية الأجزاء:
1) التهيئة: let i = 0 — تنفَّذ مرة واحدة.
2) الشرط: i < 5 — يُفحص قبل كل تكرار.
3) التحديث: i++ — ينفَّذ بعد كل تكرار.

ولا تنسوا الفاصلة المنقوطة بين الأجزاء.

for الأكثر شيوعاً في JS، لأنها دقيقة وواضحة.

المرور على مصفوفة بـfor:
const skills = ['HTML', 'CSS', 'JS'];
for (let i = 0; i < skills.length; i++) {
    console.log(i, skills[i]);
}

لاحظوا استخدام skills.length، وليس رقماً ثابتاً.
هذا أفضل، لأن المصفوفة قد تتغير.

هناك صيغة أحدث مشابهة:
for (const skill of skills) {
    console.log(skill);
}
هذه تسمى for...of، وتكرر على القيم مباشرة بلا فهرس.
أخف وأوضح، لكنها لا تعطيك الفهرس.
لو احتجت الفهرس، استخدم for التقليدية أو forEach.

وهناك for...in، لكنه للكائنات لا المصفوفات.
تجنّبوه مع المصفوفات لأنه يمر على الفهارس كنصوص.

============================================================
[60:00 – 70:00] الحلقات: while و do-while
============================================================

while يُستخدم عندما يعتمد التكرار على شرط،
وقد لا ينفّذ أبداً.

let count = 0;
while (count < 3) {
    console.log('count =', count);
    count++;
}

مفيد في:
- قراءة بيانات حتى نهاية.
- انتظار شيء.
- أي حالة لا تعرف فيها عدد التكرارات مسبقاً.

تحذير كبير: احذروا الحلقات اللانهائية.
لو نسيت i++ أو count++، ستبقى الحلقة تعمل للأبد.
المتصفح سيتجمد، وستحتاج لإغلاق التبويب.

do-while مشابه، لكن ينفّذ الكود مرة على الأقل،
ثم يفحص الشرط:

let num = 10;
do {
    console.log('num =', num);
    num++;
} while (num < 3);
// سيطبع 10 مرة واحدة، ثم يتوقف.

مفيد في قوائم "أعد المحاولة" أو في "اقرأ ثم اسأل".
استخدامه أقل شيوعاً، لكن اعرفوه.

هناك أدوات أيضاً في الحلقات:
- break: يوقف الحلقة فوراً.
- continue: يتجاوز التكرار الحالي فقط.

مثال:
for (let i = 0; i < 10; i++) {
    if (i === 5) break;
    console.log(i);   // 0..4
}

for (let i = 0; i < 10; i++) {
    if (i % 2 === 0) continue;
    console.log(i);   // 1, 3, 5, 7, 9
}

[70:00 – 90:00] الدوال: التعريف والمعاملات وreturn
============================================================

الآن أهم جزء في المحاضرة: الدوال.

الدالة كتلة كود لها اسم، تُنفَّذ عند استدعائها.
فائدتها:
- تجنّب التكرار.
- تنظيم الكود.
- تسهيل الاختبار.

أبسط دالة:
function greet() {
    console.log('مرحباً');
}
greet();

دالة بمعاملات:
function greetUser(name) {
    console.log(`مرحباً يا ${name}`);
}
greetUser('سارة');

دالة تُرجع قيمة:
function add(a, b) {
    return a + b;
}
const sum = add(5, 3);    // 8
console.log(sum);

الفرق بين console.log وreturn مهم جداً:

console.log تطبع قيمة في الطرفية، ولا تُرجع شيئاً.
return تُرجع القيمة للكود المستدعي، فيمكن استخدامها.

مثال يوضح الخطأ:

function addBad(a, b) {
    console.log(a + b);
}
const r1 = addBad(2, 3);    // yطبع 5
// r1 = undefined
// لو حاولت r1 * 2 ستحصل على NaN

function addGood(a, b) {
    return a + b;
}
const r2 = addGood(2, 3);   // 5
console.log(r2 * 2);        // 10

القاعدة: استخدم return إذا كنت تحتاج القيمة.
استخدم console.log إذا كنت تريد فقط رؤية النتيجة.

return له أيضاً وظيفة ثانية: يوقف تنفيذ الدالة.
بمجرد الوصول لـreturn، لا يُنفَّذ شيء بعده.

مثال:

function checkAge(age) {
    if (age < 0) {
        return 'عمر غير صالح';
    }
    if (age >= 18) {
        return 'بالغ';
    }
    return 'قاصر';
}

شاهدوا كيف يعود مبكراً عند أول حالة متحققة.
هذا نمط شائع جداً، يُسمى Early Return.
أنظف من if متداخلة.

============================================================
[90:00 – 100:00] النطاق وأنواع الدوال
============================================================

النطاق (Scope) مهم. عرّفنا في المحاضرة السابقة المتغيرات،
لكن أين يعيش المتغير؟ هذا هو النطاق.

ثلاثة أنواع أساسية:

1) Global — متغيرات في أعلى الملف.
   متاحة في كل مكان.
   الإكثار منها خطر: تصطدم بأسماء أخرى.

2) Function — متغيرات داخل دالة.
   لا تخرج خارجها.
   محمية من التداخل.

3) Block — متغيرات داخل { } في let وconst.
   لا تعمل مع var.
   شائعة في الحلقات والشروط.

مثال:
const appName = 'المساق';    // Global

function showTotal() {
    const total = 100;       // Function scope
    if (total > 50) {
        const msg = 'كبير';   // Block scope
        console.log(appName, total, msg);   // الكل متاح
    }
    // console.log(msg);     // خطأ — خارج الكتلة
}

showTotal();
// console.log(total);      // خطأ — خارج الدالة

الآن أنواع تعريف الدوال. ثلاثة أنواع شائعة:

1) Function Declaration:
   function square(n) { return n * n; }
   يمكن استدعاؤها قبل تعريفها (hoisting).

2) Function Expression:
   const cube = function (n) { return n * n * n; };
   لا يمكن استدعاؤها قبل تعريفها.

3) Arrow Function:
   const double = n => n * 2;
   const add = (a, b) => a + b;

Arrow مختصرة جداً، وهي شائعة في دوال المصفوفات:

const nums = [1, 2, 3, 4];
const squared = nums.map(n => n * n);
// [1, 4, 9, 16]

متى نستخدم أي نوع؟
- Arrow للدوال القصيرة، خاصة داخل map/filter/forEach.
- Function Declaration للدوال الرئيسية، لأن اسمها يظهر في تتبع الأخطاء.
- Function Expression نادرة الاستخدام اليوم.

============================================================
[100:00 – 115:00] دوال المصفوفات الحديثة
============================================================

في المحاضرة السابقة تعلّمنا push وpop وlength.
اليوم نضيف أدوات أقوى، وأكثر أناقة.

1) forEach — المرور دون إرجاع:
   numbers.forEach(n => console.log(n));
   لا تُرجع شيئاً، فقط تمر.

2) map — تحويل:
   const doubled = numbers.map(n => n * 2);
   تُرجع مصفوفة جديدة بنفس الطول.

3) filter — تصفية:
   const evens = numbers.filter(n => n % 2 === 0);
   تُرجع عناصر تحقق شرطاً، وقد تطول أقصر.

4) reduce — تجميع:
   const total = numbers.reduce((s, n) => s + n, 0);
   تُرجع قيمة واحدة.

5) find — أول تطابق:
   const first = numbers.find(n => n > 3);

6) some / every — اختبارات:
   numbers.some(n => n > 10);   // هل يوجد؟
   numbers.every(n => n > 0);   // هل كلها؟

7) includes — احتواء:
   skills.includes('JS');

كل هذه الأدوات لا تُعدّل المصفوفة الأصلية. تُرجع جديدة.
هذا نمط حديث مهم: البرمجة غير المتغيرة.

مثال على تركيبة قوية:
const evenSum = numbers
    .filter(n => n % 2 === 0)
    .reduce((s, n) => s + n, 0);

سطران يعبّران عن "اجمع الأعداد الزوجية". واضح ومقروء.

تحذير: لا تنسوا قيمة البداية في reduce:
reduce((s, n) => s + n, 0)
القيمة 0 ضرورية، خاصة مع مصفوفة فارغة.

[115:00 – 125:00] try/catch
============================================================

الأخطاء جزء طبيعي. try/catch تحميك من الانهيار.

try {
    // كود قد يفشل
    const data = JSON.parse(someString);
} catch (error) {
    console.error('فشل التحليل:', error.message);
} finally {
    console.log('انتهت المحاولة');
}

الأجزاء الثلاثة:
- try: كود قد يفشل.
- catch: يستقبل كائن الخطأ.
- finally: ينفَّذ دائماً (اختياري).

الأخطاء غير المتوقعة:
- JSON.parse على نص خاطئ.
- fetch على شبكة معطلة.
- قراءة ملف غير موجود.
- تحويل نوع غير صالح.

أما المدخلات، فتحقق منها يدوياً بـif و throw:

function divide(a, b) {
    if (typeof a !== 'number' || typeof b !== 'number') {
        throw new Error('يجب تمرير أرقام');
    }
    if (b === 0) {
        throw new Error('لا يمكن القسمة على صفر');
    }
    return a / b;
}

try {
    console.log(divide(10, 2));   // 5
    console.log(divide(10, 0));   // سيُطلق خطأ
} catch (err) {
    console.error('فشلت العملية:', err.message);
}

console.log('البرنامج يستمر');

لاحظوا السطر الأخير: "البرنامج يستمر".
هذا هو الهدف: ألا تتوقف الصفحة لأن عملية واحدة فشلت.

قاعدة عملية: try/catch للأخطاء غير المتوقعة.
التحقق من المدخلات يُكتب يدوياً بـif.
لا تستخدم try بدل التحقق المنطقي.

[125:00 – 140:00] التطبيق العملي
============================================================

الآن التطبيق. ثلاث دالات قصيرة.

التحدي الأول: FizzBuzz.

المطلوب: دالة fizzbuzz(n) تطبع الأرقام من 1 إلى n:
- إن كان الرقم يقبل القسمة على 3 و5، اطبع FizzBuzz.
- إن كان على 3 فقط، اطبع Fizz.
- إن كان على 5 فقط، اطبع Buzz.
- غير ذلك، اطبع الرقم.

البنية:

function fizzbuzz(n) {
    if (typeof n !== 'number' || n < 1) {
        throw new Error('المدخل يجب أن يكون رقماً موجباً');
    }
    for (let i = 1; i <= n; i++) {
        if (i % 15 === 0) {
            console.log('FizzBuzz');
        } else if (i % 3 === 0) {
            console.log('Fizz');
        } else if (i % 5 === 0) {
            console.log('Buzz');
        } else {
            console.log(i);
        }
    }
}

التحدي الثاني: مجموع الأعداد الزوجية.

function sumEven(arr) {
    if (!Array.isArray(arr)) {
        throw new Error('المدخل يجب أن يكون مصفوفة');
    }
    return arr
        .filter(n => n % 2 === 0)
        .reduce((s, n) => s + n, 0);
}

التحدي الثالث: عدّاد الكلمات.

function wordCount(text) {
    if (typeof text !== 'string') {
        throw new Error('المدخل يجب أن يكون نصاً');
    }
    return text
        .split(' ')
        .filter(w => w.trim().length > 0)
        .length;
}

اختبروها جميعاً في Console، ثم جرّبوا إدخال قيم خاطئة،
ولاحظوا كيف يلتقط catch الخطأ دون انهيار السكربت.

معيار الإنجاز:
- الثلاث دالات تعمل.
- console يعرض النتائج الصحيحة.
- try/catch يلتقط الأخطاء.
- كل دالة تفعل شيئاً واحداً.
- الأسماء شرح نفسها.

[140:00 – 148:00] أخطاء شائعة
============================================================

أولاً: خلط = و===.
   if (x = 5) تعيّن دائماً 5، ثم تعتبر الشرط صحيحاً.
   استخدم === للمقارنة، = للتعيين.

ثانياً: حلقة لانهائية.
   نسيت i++ أو break. المتصفح يتجمد.
   تحقق من شرط الحلقة قبل التشغيل.

ثالثاً: نسيان return.
   دالة تستخدم console.log فقط تُرجع undefined.
   أضف return إذا احتجت القيمة.

رابعاً: تعديل المصفوفة أثناء المرور.
   حذف عنصر في forEach يسبب تخطي آخر.
   استخدم filter لإنشاء جديدة.

خامساً: reduce بلا قيمة بداية.
   تفشل مع مصفوفة فارغة.
   دائماً مرّر 0 (أو أي قيمة مناسبة).

سادساً: try/catch لكل شيء.
   للأخطاء غير المتوقعة فقط. التحقق اليدوي أفضل للمدخلات.

سابعاً: arrow بجسم معقوف بلا return.
   x => { x * 2 } لا تُرجع شيئاً.
   إما x => x * 2، أو x => { return x * 2; }.

ثامناً: دالة تفعل كل شيء.
   اكتب دوالاً صغيرة، كل واحدة مسؤولية واحدة.

نصائح:
- اطبع القيم قبل السطور التي لا تعمل.
- اختبر كل دالة منفصلة.
- ابدأ بالحالة البسيطة.
- اقرأ رسائل الأخطاء حرفياً.
