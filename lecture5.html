لماذا التصميم المتجاوب

قبل عصر الهواتف، كانت المواقع تُصمَّم لعرض ثابت (غالباً 960px أو 1024px). اليوم، أكثر من نصف الزيارات تأتي من شاشات مختلفة الأحجام: هواتف صغيرة، هواتف كبيرة، أجهزة لوحية، حواسيب محمولة، شاشات 4K. التصميم المتجاوب (Responsive Design) هو ببساطة: تصميم واحد يتكيف مع كل هذه الأحجام دون أن يصبح غير قابل للاستخدام.

تخطيط سائل

  • عروض تعتمد على % أو fr
  • لا عرض ثابت قسري
  • يتمدد ويتقلص مع الشاشة
  • أساس كل تجاوب

وسائط مرنة

  • img { max-width: 100%; }
  • الصور تتقلص مع الحاوية
  • لا فيديو أفقي يفوت الشاشة
  • جودة الحفاظ على النسب

استعلامات وسائط

  • تغيير التخطيط عند نقاط محددة
  • @media (min-width: 768px)
  • يفصل بين أحجام الأجهزة
  • بديل ذكي للتخطيطات الثابتة

أهداف لمس مناسبة

  • الحجم الأدنى المستحسن 44×44px
  • مسافات كافية بين الأزرار
  • منع النقر بالخطأ
  • مهم للوصولية أيضاً
مبدأ الهاتف أولاً (Mobile-first): ابدأ بتصميم الهاتف — عمود واحد، خطوط واضحة، أزرار كبيرة — ثم أضف التحسينات للشاشات الأكبر باستخدام @media (min-width: …). هذا يضمن أنك لا تحاول "ضغط" تخطيط كبير داخل هاتف صغير.

وحدات القياس في CSS

اختيار الوحدة الصحيحة هو نصف التجاوب. الوحدات تنقسم إلى قسمين: مطلقة لا تتغير بحسب السياق (مثل px)، ونسبية تعتمد على شيء آخر — حجم الجذر، الأب، أو أبعاد الشاشة.

الوحدة النوع تُحسب نسبة إلى الاستخدام المفضل
px مطلقة بكسل الشاشة الحدود، الظلال، التفاصيل الدقيقة
% نسبية الأب عروض مرنة
em نسبية حجم خط العنصر الأب مسافات تتناسب مع نص مكون
rem نسبية حجم خط جذر المستند حجم النصوص والمسافات الكبيرة
vh / vw نسبية 1% من ارتفاع/عرض نافذة العرض أقسام بملء الشاشة، وسائد بصرية
vmin / vmax نسبية الأصغر/الأكبر من vw وvh تخطيطات تعتمد على الشاشة كاملة
ch نسبية عرض المحرف "0" عرض يسهل القراءة (65ch شائع)
fr خاصة بـGrid جزء من المساحة المتاحة توزيع أعمدة Grid
units.css CSS 
/* تجربة سريعة: كيف تتغير الوحدات؟ */
html { font-size: 18px; }

.box-px    { width: 320px; }                    /* ثابت لا يتغير */
.box-pct   { width: 80%; }                      /* نسبة من الأب */
.box-rem   { width: 20rem; padding: 1.5rem; }   /* 20 × 18px */
.box-em    { font-size: 20px; padding: 2em; }   /* 2 × 20 = 40px */
.box-vh    { min-height: 100vh; }               /* يملأ الشاشة طولاً */
.box-ch    { max-width: 65ch; }                 /* عرض مريح للقراءة */

/* أنماط المستند الأساسي — نمط مقترح */
html {
    font-size: 1rem;   /* 1rem = 16px عادة */
}
body {
    font-size: 1rem;        /* استخدم rem للنصوص */
    line-height: 1.7;       /* بلا وحدة — نسبة إلى font-size */
}
قاعدة عملية: استخدم rem للنصوص والمسافات الكبيرة، px للحدود والظلال، % وfr للعروض داخل التخطيطات، وvh لأقسام تحتاج ملء الشاشة. لا تخلط الوحدات داخل نفس الخاصية بلا سبب.
تنبيه: vh له مشكلة معروفة في متصفحات الهاتف — ارتفاع شريط العنوان/الإعدادات يتغير مع التمرير، فيتغير ارتفاع العناصر بملء الشاشة. بديل حديث: 100dvh (dynamic viewport height). استخدمه عند توفره.

مقدمة إلى Flexbox

Flexbox هو نموذج تخطيط أحادي البعد: يوزّع العناصر على محور واحد (صف أو عمود). مُثالي لشريط تنقل، زر مع أيقونة، قائمة بطاقات في صف، أو توسيط عنصر في وسطه تماماً.

عند وضع display: flex على عنصر، يصبح هو الحاوية المرنة (flex container)، وكل أبنائه المباشرين يصبحون عناصر مرنة (flex items). يمكنك بعدها التحكم باتجاه المحور، وكيفية التوزيع، والمحاذاة العمودية، والتفاف العناصر.

المحور الرئيسي

  • صف افتراضيًا (Main axis)
  • flex-direction: row
  • تتحكم به justify-content
  • يمكن قلبه بـrow-reverse

المحور المتقاطع

  • عمودي افتراضيًا (Cross axis)
  • عكس اتجاه المحور الرئيسي
  • تتحكم به align-items
  • لعمل عمود: flex-direction: column
flexbox-basic.css CSS 
.nav {
    display: flex;              /* يفعّل Flexbox */
    gap: 12px;                  /* مسافة بين العناصر */
    flex-direction: row;        /* صف (افتراضي) */
    justify-content: space-between; /* توزيع على المحور الرئيسي */
    align-items: center;        /* توسيط عمودي */
    padding: 12px 20px;
    background: #0b1120;
}

.nav a {
    color: #7dd3fc;
    text-decoration: none;
    padding: 6px 10px;
}

Flexbox: التوزيع والمحاذاة والالتفاف

بعد تفعيل Flexbox، أهم خصائص الحاوية هي: justify-content (توزيع على المحور الرئيسي)، align-items (محاذاة على المحور المتقاطع)، gap (مسافة بين العناصر)، وflex-wrap (هل تنتقل العناصر إلى سطر جديد عند ضيق المساحة؟).

القيمة تأثيرها على المحور الرئيسي
flex-start تجميع العناصر في البداية (بداية المحور)
flex-end تجميع العناصر في النهاية
center توسيط العناصر
space-between أول عنصر في البداية، آخر في النهاية، والباقي موزع
space-around مسافة حول كل عنصر (نصف المسافة في الأطراف)
space-evenly مسافات متساوية تمامًا بين العناصر والأطراف

align-items (المحور المتقاطع)

  • stretch (افتراضي)
  • flex-start / flex-end
  • center — شائع جدًا
  • baseline لمحاذاة خط الأساس

flex-wrap

  • nowrap (افتراضي — لا التفاف)
  • wrap — التفاف عند الحاجة
  • wrap-reverse — التفاف معكوس
  • ضروري لقوائم البطاقات المرنة

خصائص العنصر

  • flex: 1 — تمدد متساوٍ
  • flex: 2 — ضعف التمدد
  • flex-grow / shrink
  • flex-basis — الحجم الأولي
flexbox-card-row.css CSS 
.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

.cards .card {
    flex: 1 1 280px;      /* grow:1, shrink:1, basis:280px */
    background: #1b2540;
    border-radius: 12px;
    padding: 16px;
}

/* توسيط دقيق لعنصر في وسطه */
.centered {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}
حيلة التوسيط الشهيرة: display:flex مع justify-content:center وalign-items:center هي أسهل طريقة لتوسيط عنصر أفقيًا وعموديًا. لا حاجة إلى هوامش سالبة أو position: absolute.
تحذير شائع: flex: 1 يجعل العنصر ينمو لملء المساحة. إذا أضفت flex: 1 لثلاث بطاقات، ستتساوى عروضها. لكن إذا لم تعطِ عنصرًا أي flex، سيبقى بحجم محتواه فقط — أحيانًا هذا هو ما تريده، وأحيانًا لا. انتبه.

مقدمة إلى Grid

Grid هو نموذج تخطيط ثنائي الأبعاد: يتعامل مع الصفوف والأعمدة في آن واحد. إنه الأداة المثالية لبناء شبكة بطاقات، صفحة كاملة بأقسامها، أو معرض صور.

على الحاوية نضع display: grid، ثم نحدد أعمدة الشبكة عبر grid-template-columns، وصفوفها إن أردنا عبر grid-template-rows. المسافة بين الخلايا عبر gap.

grid-basic.css CSS 
/* ثلاث أعمدة متساوية */
.grid-3 {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

/* شبكة متجاوبة تلقائيًا */
.grid-auto {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
    gap: 16px;
}

/* شبكة بنمط محدد: 200px ثم الباقي */
.grid-mixed {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    gap: 16px;
}

repeat()

  • repeat(3, 1fr) = 3 أعمدة متساوية
  • repeat(auto-fit, minmax(260px, 1fr))
  • يقلل التكرار اليدوي
  • الأساس لشبكة متجاوبة ذكية

fr

  • جزء من المساحة المتاحة
  • 1fr 1fr 1fr = ثلث لكل عمود
  • 2fr 1fr = 2/3 و1/3
  • أكثر مرونة من النسب المئوية

auto-fit vs auto-fill

  • auto-fit — يمدد البطاقات لملء الصف
  • auto-fill — يترك فراغًا لو المتبقي قليل
  • غالبًا auto-fit للبطاقات
  • الاثنان يحتاجان minmax
أشهر نمط شبكة متجاوبة:
grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
هذا السطر وحده يعطيك شبكة تتكيف تلقائيًا: عمود واحد على الهاتف، عمودان على اللوحي، ثلاثة أو أكثر على الحاسوب. بدون Media Query.

الفرق بين Flexbox وGrid

السؤال الأكثر تكرارًا: أيّهما أستخدم؟ الجواب: كل واحد لما بُني له. Flexbox يعمل على محور واحد، Grid يعمل على محورين. والاثنان يتكاملان.

المحور Flexbox Grid
الأبعاد أحادي (صف أو عمود) ثنائي (صفوف وأعمدة)
متى نستخدمه شريط تنقل، صف أزرار، توسيط شبكة بطاقات، تخطيط صفحة، معرض صور
الاعتماد على المحتوى غالبًا يعتمد على محتوى العناصر غالبًا تحدد الشبكة قبل المحتوى
التحكم الافتراضي متصفح يوزع العناصر أنت تحدد الأعمدة والصفوف
في التخطيط العام عنصر داخلي تخطيط الصفحة الأساسي
نمط عملي شائع: استخدم Grid لتخطيط الصفحة الرئيسي (ترويسة / شريط جانبي / محتوى / تذييل)، واستخدم Flexbox داخل المكونات (شريط تنقل، صف أزرار، بطاقة فيها صورة ونص بجانب بعضهما).

Media Queries والتصميم من الهاتف أولاً

Media Queries هي الجملة الشرطية في CSS: "إذا كانت الشاشة أعرض من كذا، طبّق هذه القواعد". تكتبها هكذا: @media (min-width: 768px) { ... }.

في أسلوب Mobile-first، تكتب الأنماط الأساسية للهاتف أولاً (بدون Media Query)، ثم تُضيف تحسينات للشاشات الأكبر باستخدام min-width. هذا الترتيب يمنع التعارضات ويضمن أن الهاتف دائمًا يحصل على النسخة الأساسية.

responsive-layout.css CSS 
/* ==== الأساس: هاتف أولاً ==== */
.layout {
    display: grid;
    grid-template-columns: 1fr;   /* عمود واحد */
    gap: 16px;
    padding: 16px;
}

/* ==== لوحي: 768px فأكثر ==== */
@media (min-width: 768px) {
    .layout {
        grid-template-columns: 1fr 1fr;  /* عمودان */
        padding: 24px;
        gap: 20px;
    }
}

/* ==== حاسوب: 1024px فأكثر ==== */
@media (min-width: 1024px) {
    .layout {
        grid-template-columns: 240px 1fr; /* شريط جانبي + محتوى */
        padding: 32px;
        max-width: 1200px;
        margin: 0 auto;
    }
}

نقاط التوقف الشائعة

  • 480px — هاتف كبير
  • 640px — لوحي صغير
  • 768px — لوحي
  • 1024px — حاسوب محمول
  • 1280px — سطح مكتب

min-width أم max-width

  • min-width — Mobile-first (مفضّل)
  • max-width — Desktop-first (قديم)
  • لا تخلط بين الاثنين
  • اختر نمطًا والتزم به

أنواع الوسائط

  • screen — الشاشات
  • print — الطباعة
  • prefers-reduced-motion
  • prefers-color-scheme — داكن/فاتح
لا تكتب Media Query لكل بكسل. النقاط يجب أن تُختار عندما "ينكسر" التصميم فعلًا، لا لمجرد تقليد أرقام مشهورة. ابدأ بعمود واحد، وسّعه، لاحظ متى يصبح غير مريح، ثم أضف نقطة التوقف عنده.

اختبار التخطيطات في أدوات المطور

أدوات المطور توفر وضع محاكاة الأجهزة الذي يسمح باختبار أي صفحة على أحجام شاشات متعددة. هذا لا يغني عن الاختبار على جهاز حقيقي، لكنه يسرّع التطوير كثيرًا.

Device Mode

  • افتح أدوات المطور بـF12
  • اضغط أيقونة الهاتف (Ctrl+Shift+M)
  • اختر جهازًا من القائمة
  • غيّر الاتجاه عمودي/أفقي

تغيير الحجم اليدوي

  • اسحب حدود النافذة
  • لاحظ عرض الحاوية بالأعلى
  • راقب متى تنهار التخطيطات
  • أضف نقطة توقف عندها

فحص Flex وGrid

  • شعار Flex/Grid بجانب العنصر
  • يفعّل تراكب المحاور
  • يساعد على فهم التوزيع
  • جرّبه في تبويب Elements

الفرق عن الجهاز الحقيقي

  • لا يعرض لوحة مفاتيح فعلية
  • لا يحاكي سرعة الشبكة افتراضيًا
  • لا يظهر سلوك اللمس الحقيقي
  • اختبر دائمًا على جهاز واحد فعلي

التطبيق العملي

المطلوب في هذه المحاضرة بناء صفحة تحتوي عمودين على الشاشات الكبيرة، ويتحولان إلى عمود واحد على الهاتف. سنستخدم Grid للتخطيط الأساسي، وFlexbox داخل العناصر.

تطبيق المحاضرة 5

  1. أنشئ ملف layout.html داخل مجلد web-course.
  2. اكتب مستند HTML5 كاملًا مع هيكل دلالي: header، main، footer.
  3. داخل main أنشئ عنصرًا بحاوية: <div class="layout">، وبداخله عنصران:
    • <article class="content"> — محتوى رئيسي.
    • <aside class="sidebar"> — بطاقة جانبية.
  4. أضف صفًا من الأزرار في header وتحكّم به باستخدام Flexbox (توسيط، مسافة).
  5. في style.css أنشئ قاعدة أساسية (Mobile-first):
    • .layout { display: grid; grid-template-columns: 1fr; gap: 16px; padding: 16px; }
  6. أضف Media Query للشاشات الكبيرة:
    • @media (min-width: 768px) { .layout { grid-template-columns: 2fr 1fr; padding: 24px; } }
  7. أنشئ شبكة بطاقات داخل article:
    • .cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 12px; }
    • ضع بداخلها 4–6 بطاقات صغيرة.
  8. استخدم rem للنصوص والمسافات، وpx للحدود.
  9. افتح الصفحة في وضع الأجهزة بأدوات المطور، وجرّب العرض على 360px و768px و1280px.
  10. تأكد أن الأزرار في الترويسة تبقى في صف واحد على الحاسوب، وتلتف على الهاتف.
  11. التقط صورة للصفحة على الهاتف وصورة على الحاسوب، وأرفقهما مع layout.html وstyle.css.
معيار الإنجاز: بدون Media Queries مكتوبة يدويًا للبطاقات، تتكيف شبكة البطاقات تلقائيًا. وفي وضع الهاتف، .layout عمود واحد بلا تمرير أفقي. لا يوجد overflow-x: scroll على body.

أخطاء شائعة ونصائح

استخدام عرض ثابت

width: 1200px سيسبب تمريرًا أفقيًا على الهاتف. استخدم max-width بدلًا من width للعناصر الأساسية.

خلط min-width مع max-width

إذا بدأت بـmin-width، التزم به. خلط الاثنين يُنتج تعارضات غامضة تتطلب !important لحلها.

نسيان max-width على الصور

صورة كبيرة داخل عمود ضيق ستدفع الصفحة للتمرير. أضف دائمًا: img { max-width: 100%; height: auto; }.

نقاط توقف كثيرة

ثلاث نقاط توقف كافية لمعظم المشاريع. كل نقطة إضافية تعني مزيدًا من الصيانة. اختر بناءً على "متى ينكسر التصميم؟".

أهداف لمس صغيرة

أزرار بحجم 24px صعبة على الإبهام. استخدم min-height: 44px وpadding مريح. هذا مهم للوصولية أيضًا.

الاعتماد على hover فقط

:hover لا يعمل على اللمس. لا تجعل وظيفة حرجة تعتمد فقط على المرور بالفأرة. أضف بديلًا عبر :focus و:active.

ملخص المحاضرة

  • التصميم المتجاوب: تخطيط واحد يتكيف مع كل أحجام الشاشات.
  • وحدات القياس: px مطلق، rem و% وvh وfr نسبية.
  • Flexbox أحادي البعد: صف أو عمود، مع justify-content وalign-items.
  • Grid ثنائي الأبعاد: شبكة صفوف وأعمدة، مع fr وrepeat() وminmax().
  • النمط الذكي: repeat(auto-fit, minmax(260px, 1fr)) لشبكة تلقائية التجاوب.
  • Media Queries تكتب بأسلوب Mobile-first عبر min-width.
  • نقاط التوقف تُختار عند انكسار التصميم، لا بتقليد أرقام جاهزة.
  • أدوات المطور توفر وضع أجهزة لاختبار التخطيطات بسرعة.
  • الوصولية: أهداف لمس 44px+، لا اعتماد على hover فقط، تمرير أفقي غير مقصود ممنوع.

تقييم سريع

1) ما الفرق بين px وrem؟

px وحدة مطلقة لا تتغير بحسب السياق. rem نسبية تُحسب من حجم خط جذر المستند (html)، فتحترم إعدادات المستخدم وتكبر معها.

2) متى نستخدم Flexbox ومتى نستخدم Grid؟

Flexbox للتخطيطات أحادية البعد (صف أو عمود) مثل شريط التنقل. Grid للتخطيطات ثنائية الأبعاد (صفوف وأعمدة معًا) مثل شبكة البطاقات أو تخطيط الصفحة.

3) ماذا تفعل repeat(auto-fit, minmax(260px, 1fr))؟

تبني شبكة تلقائية: عدد الأعمدة يتحدد تلقائيًا حسب عرض الحاوية، كل عمود لا يقل عن 260px ويمتد لملء المساحة المتبقية (1fr). النتيجة: تجاوب تلقائي بدون كتابة Media Queries للبطاقات.

4) لماذا نفضّل Mobile-first؟

لأن الهاتف أبسط تخطيط، والبدء به ثم التوسع أبسط من تقليص تخطيط كبير. كما أنه يضمن أنك لا تتجاهل تحسينات الهاتف، ويمنع تعارضات تنتج عن خلط min-width وmax-width.

5) لماذا نحتاج img { max-width: 100%; height: auto; }؟

لأن الصور الكبيرة قد تتجاوز عرض الحاوية على الهاتف، فتُسبب تمريرًا أفقيًا غير مقصود. max-width: 100% يُقلّصها تلقائيًا داخل الحاوية مع الحفاظ على النسب.
