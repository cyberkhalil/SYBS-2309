[03:00 – 12:00] ما هي Python ولماذا نتعلمها
============================================================

Python لغة برمجة عالية المستوى، صمّمها Guido van Rossum
في أوائل التسعينيات. سُميت بهذا الاسم نسبة إلى فرقة
Monty Python الكوميدية، لا إلى الثعبان، ولكن الشعار
صار ثعباناً لاحقاً.

ما يميز Python؟

أولاً: القراءة. الكود يشبه الإنجليزية الطبيعية. قارن:
في JavaScript تكتب:
if (x > 5) {
    console.log("كبير");
}
في Python تكتب:
if x > 5:
    print("كبير")

أوضح، أقصر، بلا أقواس أو أقواس معقوفة. الإزاحة هي التي تحدد
الكتلة. هذه ميزة كبيرة، لكن لها ثمن: لا تخطئ في المسافات.

ثانياً: الحضور القوي. Python اليوم في الويب (Flask, Django),
وفي تحليل البيانات، والذكاء الاصطناعي، والأمن السيبراني،
والأتمتة. هي لغة "العصر" بلا منازع.

ثالثاً: المكتبة القياسية الضخمة. تقريباً كل شيء تحتاجه
موجود جاهزاً: JSON، HTTP، قواعد البيانات، معالجة النصوص.

لماذا اخترناها لجهة الخادم في المساق؟ لأننا نريد التركيز
على مفاهيم الويب لا على تعقيد اللغة. Flask نفسه صغير وواضح،
ويعطينا صورة كاملة عن تطوير الخادم دون تعقيد Django الكامل.

ملاحظة للطلبة القادمين من JavaScript:
Python ليست صعبة، لكن هناك ثلاث عادات يجب تغييرها:
1. الإزاحة إلزامية، ليست ذوقاً.
2. لا توجد أقواس معقوفة للكتل.
3. اصطلاح الأسماء snake_case، لا camelCase.

تنبيه: Python 2 ميت دعماً منذ 2020. كل ما نستخدمه هنا هو Python 3،
وأي مصدر يذكر Python 2 تجاهلوه.

============================================================
[25:00 – 38:00] REPL مقابل السكربتات
============================================================

عند تشغيل Python ماذا يحدث؟ هناك طريقتان رئيسيتان.

الطريقة الأولى: REPL.
افتحوا الطرفية واكتبوا python (أو python3 على Mac/Linux).
ستظهر لكم علامة &gt;&gt;&gt; — هذه تعني أنكم في الوضع التفاعلي.
كل سطر تكتبونه ينفّذ فوراً ويُطبع ناتجه.
مثال:
&gt;&gt;&gt; 2 + 3
5
&gt;&gt;&gt; print("مرحباً")
مرحباً
&gt;&gt;&gt; name = "سارة"
&gt;&gt;&gt; name.upper()
'سارة'
&gt;&gt;&gt; exit()

REPL ممتاز للتجربة السريعة: تريد أن تعرف ما تفعله دالة؟
جرّبها في REPL. تريد اختبار تعبير؟ REPL أسرع مكان.
لكن REPL لا يحفظ. بمجرد الخروج، كل شيء يُفقد.

الطريقة الثانية: ملفات السكربت.
اكتبوا الكود في ملف بامتداد .py، ثم شغّلوه بسطر:
python script.py
هنا يُنفَّذ الملف كاملاً بالترتيب.

هذا هو الخيار الحقيقي للبرامج، للتسليمات، للمشاريع.
كل الأمثلة التي سنكتبها اليوم ستكون في ملفات .py.

في VS Code، يمكنكم تشغيل السكربت مباشرة بزر Run
أو بالضغط على F5، لكن تعوّدوا على تشغيله من الطرفية أيضاً،
لأن ذلك مهارة أساسية عند العمل على خادم لاحقاً.

نصيحة أخيرة على REPL: للخروج استخدموا exit() أو Ctrl+D
في Linux/Mac، أو Ctrl+Z ثم Enter في Windows.
لا تغلقوا النافذة فقط — اغلقوا REPL بشكل صحيح.

[38:00 – 52:00] المتغيرات والأنواع المدمجة
============================================================

نأتي إلى أول كود حقيقي.

أنشئوا ملفاً اسمه first.py. اكتبوا فيه:

print("مرحباً بك في Python")

name = "سارة"
age = 20
is_student = True

print(f"الاسم: {name} — العمر: {age} — طالب: {is_student}")

شغّلوه:
python first.py

لاحظوا:
- لا نستخدم let أو const أو var. نكتب الاسم مباشرة.
- Python تفهم النوع من القيمة تلقائياً.
- f-string يبدأ بـ f، ويُدخل القيم بين { }.

الآن، المتغيرات في Python:
هي أسماء مرتبطة بكائنات. الاسم camelCase هنا خطأ اصطلاحاً.
الاصطلاح هو snake_case: user_name لا userName.

قواعد التسمية:
- أحرف إنجليزية وأرقام و _ فقط.
- لا تبدأ برقم.
- لا تستخدم كلمات محجوزة (if، for، class، def…).
- أسماء وصفية، لا مختصرة.

الأنواع المدمجة الأساسية:
- str: نص. "مرحباً" أو 'Hello'.
- int: عدد صحيح. 42 أو -7.
- float: عدد عشري. 3.14.
- bool: True أو False (بحرف كبير أولاً!).
- None: قيمة "لا شيء" متعمدة.

وهناك أنواع مركبة:
- list: قائمة مرتبة. [1, 2, 3].
- dict: قاموس. {"name": "سارة"}.
- tuple: قائمة ثابتة. (1, 2, 3).

للتحقق من النوع، استخدموا type():
print(type("مرحباً"))    # &lt;class 'str'&gt;
print(type(42))           # &lt;class 'int'&gt;
print(type(3.14))         # &lt;class 'float'&gt;
print(type(True))         # &lt;class 'bool'&gt;
print(type(None))         # &lt;class 'NoneType'&gt;

ملاحظة مهمة: bool بحرف كبير أولاً. لو كتبتم true أو false
بحروف صغيرة، Python لن تعرفها — NameError.

نقطة أخرى على None: تعني "لا قيمة" متعمدة.
مفيدة لاحقاً عند التحقق "هل تم تعيين هذا أم لا".

الآن، الثوابت:
Python لا تفرض الثوابت. لكن الاصطلاح أن نكتب المتغيرات
التي لا تتغير بحروف كبيرة:
TAX_RATE = 0.05
APP_NAME = "حاسبة البقشيش"

هذا اتفاق بين المبرمجين، لا فرض من اللغة.

[52:00 – 68:00] الأرقام والنصوص والتحويل
============================================================

نأتي إلى الأرقام.

a = 10
b = 3

print(a + b)      # 13
print(a - b)      # 7
print(a * b)      # 30
print(a / b)      # 3.3333… (float دائماً)
print(a // b)     # 3 (قسمة صحيحة)
print(a % b)      # 1 (باقي القسمة)
print(a ** b)     # 1000 (الأس)

round(3.14159, 2)   # 3.14
abs(-7)              # 7

وثانياً، النصوص.

text = "  مرحباً بالعالم  "

text.strip()                # "مرحباً بالعالم"
"hello world".replace("world", "Python")
"a, b, c".split(", ")       # ['a', 'b', 'c']
"-".join(['a', 'b', 'c'])   # "a-b-c"
len("مرحباً")               # 6

الفهرسة والتقطيع:
s = "Python"
s[0]      # P
s[-1]     # n
s[0:3]    # Pyt
s[:3]     # Pyt
s[3:]     # hon

الآن، التحويل بين الأنواع. هذه مهارة أساسية لأن مدخلات
المستخدم نصوص دائماً:

int("42")        # 42
float("3.14")    # 3.14
str(42)          # "42"
int(3.99)        # 3 (يقتطع، لا يقرّب)
float(7)         # 7.0

لكن انتبهوا: التحويل قد يفشل.
int("abc")   # ValueError

لهذا قدّمنا try/except:
try:
    n = int("abc")
except ValueError:
    print("قيمة غير صالحة")

هذه القاعدة: أي تحويل من نص إلى رقم، لفّوه في try/except.
أشهر سبب لانهيار التطبيقات الصغيرة عند الطلاب هو نسيان
هذه الحماية.

نقطة على bool:
print(bool(0))       # False
print(bool(""))      # False
print(bool(None))    # False
print(bool(42))      # True
print(bool("0"))     # True  ← النص "0" غير فارغ

هذا يذكّرنا بما شرحناه في JavaScript: مفهوم truthy/falsy.
Python أيضاً تعتبر 0، ""، None، []، {} والعديد من القيم
الفارغة كأنها false في الشروط.

[68:00 – 80:00] print و input و f-strings
============================================================

print() تطبع. input() تقرأ. وهما نافذتنا للتفاعل.

print("مرحباً")
print("الاسم:", "سارة", "— العمر:", 20)
print("بدون", end="")
print(" فصل")
print("a", "b", "c", sep="-")   # a-b-c

input ترجع دائماً str:
name = input("ما اسمك؟ ")
age_str = input("كم عمرك؟ ")
age = int(age_str)          # تحويل!
print(f"مرحباً {name}، عمرك {age} سنة")

الدرس الأهم اليوم: input دائماً نص.
لو نسيت التحويل، كل العمليات الحسابية ستنهار.

الآن f-strings:
name = "سارة"
age = 20
price = 49.5

print(f"مرحباً {name}، عمرك {age} سنة")
print(f"المجموع: {price * 2}")
print(f"السعر: {price:.2f}")        # السعر: 49.50
big = 1234567
print(f"{big:,}")                    # 1,234,567

لاحظوا {price:.2f} — دقة عشرية بخانتين.
و{big:,} — فواصل الآلاف.

هذه الصيغة أقوى من الطرق القديمة (% و.format)،
وندعمها من Python 3.6. استخدموها وتجنّبوا البدائل القديمة.

والقواميس:
student = {
    "name": "سارة",
    "age": 20,
    "skills": ["HTML", "CSS", "Python"],
    "active": True
}

student["name"]              # سارة
student.get("age")           # 20
student.get("missing")       # None
student.get("missing", 0)    # 0 (قيمة افتراضية)

student["city"] = "غزة"

for key, value in student.items():

الفرق مع list:

- dict تعتمد المفتاح ("name").

- في Flask، سنستخدم list للقوائم، dict لكل عنصر منها.

[95:00 – 120:00] التطبيق العملي
============================================================

الآن التطبيق. ثلاث سكربتات قصيرة.

السكربت الأول: حاسبة البقشيش.

المطلوب:
- اقرأ bill و tip_percent من input.
- تحقق من صلاحية المدخلات بـtry/except.
- احسب tip و total.
- اطبع النتيجة بـf-string بخانتين عشريتين.

البنية:

try:
    bill = float(input("قيمة الفاتورة: "))
    tip_percent = float(input("نسبة البقشيش (%): "))
except ValueError:
    print("خطأ: يُرجى إدخال أرقام صحيحة.")
    exit(1)

if bill &lt;= 0 or tip_percent &lt; 0:
    print("خطأ: القيم يجب أن تكون موجبة.")
    exit(1)

tip = bill * tip_percent / 100
total = bill + tip

print(f"الفاتورة:   {bill:.2f}")
print(f"البقشيش:    {tip:.2f}")
print(f"المجموع:    {total:.2f}")

السكربت الثاني: محوّل وحدات.
البنية مشابهة. اسأل: قيمة، ونوع التحويل (C→F أو F→C).
استخدم if/elif/else.
الصيغة:
F = C * 9/5 + 32
C = (F - 32) * 5/9

السكربت الثالث: منسّق بيانات.
أنشئ قاموساً، اقرأ ثلاث قيم من المستخدم، حدّث القاموس،
اطبع النتيجة. أضف list للمهارات واطبعها.

اختبروا كل سكربت في طرفيتين مختلفتين: CLI وVS Code.
لاحظوا أن النتيجة نفسها. الفرق في الراحة فقط،
لا في التنفيذ.

وأضيفوا اختبارات "قصدية":
- اكتبوا نصاً حيث يُتوقع رقم. سيلتقطه try/except.
- اتركوا الإدخال فارغاً. القيمة النصية الفارغة ستفشل
  في float، فيلتقطها except.
- اكتبوا رقماً سالباً، وسيرفضه فحص bill &lt;= 0.

معيار الإنجاز:
- السكربتات الثلاثة تعمل بلا توقف عند مدخلات صحيحة.
- لا توقف عند مدخلات خاطئة.
- المخرجات بالعربية منسقة بـf-strings.
- لا تحذيرات أو أخطاء عند التشغيل العادي.
