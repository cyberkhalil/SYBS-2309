ما هي Python ولماذا نتعلمها

Python لغة برمجة عالية المستوى، صمّمها Guido van Rossum في أوائل التسعينيات، واشتهرت بقراءتها القريبة من اللغة الطبيعية. مبدؤها أن الكود يُكتب مرة ويُقرأ عشر مرات، لذلك فضّلت الوضوح على الاختصار. اليوم لها حضور قوي في تطوير الويب (Flask, Django)، وعلم البيانات، والأمن المعلوماتي، والأتمتة.

لماذا نختارها لجهة الخادم في هذا المساق؟ لأنها تتيح لنا التركيز على مفاهيم الويب لا على تعقيد اللغة. Flask ذاته كلغة إطار عمل صغير وواضح، ويفتح الباب لاحقاً لفهم Django وغيره.

تثبيت Python وإعداد بيئة العمل

نزّل Python من الموقع الرسمي python.org، واختر الإصدار 3.10 أو أحدث. في Windows، لا تنسَ تفعيل خيار Add Python to PATH أثناء التثبيت — بدونه لن تعمل أوامر python وpip من الطرفية. في macOS وLinux غالباً Python 3 موجود مسبقاً كـpython3.

التحقق من التثبيت SHELL

python --version
# أو

python3 --version

pip install flask
# أو
pip3 install flask

بعد تثبيت Python، ثبّت إضافة Python extension في VS Code من Microsoft. هذه الإضافة تعطيك إكمالاً تلقائياً، تنسيقاً، وتصحيحاً (debugging) مدمجاً. ثم أضف إضافة Pylance لتحسين تجربة الكتابة.

تشغيل Python: REPL مقابل السكربتات

Python تعمل بطريقتين أساسيتين: REPL (وضع تفاعلي) وملفات السكربت (ملفات .py). كلتاهما مفيدة، لكن لكل منهما سياقها.

المحور REPL السكربت (.py)
طريقة الدخول اكتب python بدون اسم ملف اكتب python script.py
التنفيذ سطر بسطر، فوري الملف كاملاً
الاستخدام الأنسب تجربة سريعة، استكشاف برامج حقيقية، تسليمات
الحفظ لا يُحفظ بعد الإغلاق يُحفظ في الملف
الخروج exit() أو Ctrl + D أو Ctrl + Z ينتهي تلقائياً
REPL — وضع تفاعلي SHELL 
$ python3
Python 3.12.0 (main, Oct  2 2023)
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 + 3
5
>>> print("مرحباً")
مرحباً
>>> name = "سارة"
>>> name.upper()
'سارة'
>>> exit()
$

لاحظ العلامة >>> التي تعني أنك داخل REPL. أي سطر تكتبه يُنفَّذ فوراً ويُطبع ناتجه. لا يمكن أن تكتب كتلة متعددة الأسطر بسهولة في REPL (رغم إمكانية ذلك بإدخال سطر فارغ). لهذا السكربتات هي الخيار الأصلي.

first.py — أول سكربت PYTHON 
# first.py — أول سكربت Python
print("مرحباً بك في Python")

# متغيرات بسيطة
name = "سارة"
age = 20
is_student = True

# طباعة باستخدام f-string
print(f"الاسم: {name} — العمر: {age} — طالب: {is_student}")
تشغيل السكربت SHELL 
$ python3 first.py
مرحباً بك في Python
الاسم: سارة — العمر: 20 — طالب: True
عادات جيدة منذ اليوم الأول: ابدأ كل سكربت بتعليق يوضح الهدف والتاريخ. ثبّت الإزاحة على 4 مسافات (لا Tab). سمّ الملفات بأسماء وصفية بحروف صغيرة: tip_calculator.py لا test1.py.
تحذير على المسارات: إذا كان مجلد مشروعك يحتوي مسافات أو حروفاً عربية، فقد تفشل بعض أوامر pip. استخدم مجلداً إنجليزياً قصيراً باسم python-course، وأنشئ السكربتات داخله.

المتغيرات والأنواع المدمجة

المتغير في Python هو اسم مرتبط بكائن. لا تحتاج لتصريح نوعه — Python تكتشفه من القيمة تلقائياً. هذا يجعل الكود أنظف، لكنه يحتّم عليك الانتباه للنوع عند التحويل.

variables.py PYTHON 
# تعريف متغيرات
name = "سارة"             # str
age = 20                  # int
height = 1.68             # float
is_student = True         # bool
nothing = None            # NoneType (قيمة فارغة متعمدة)

# التحقق من النوع
print(type(name))         # <class 'str'>
print(type(age))          # <class 'int'>
print(type(height))       # <class 'float'>
print(type(is_student))   # <class 'bool'>
print(type(nothing))      # <class 'NoneType'>
النوع أمثلة ملاحظة
str "مرحباً"، 'Hi' مفردة أو مزدوجة، لا فرق
int 42، -7، 0 أرقام صحيحة، لا حد عملي
float 3.14، 1.0e3 كسور عشرية
bool True، False حرف كبير أولاً (مهم)
None None قيمة "لا شيء" متعمدة
list [1, 2, 3] قائمة مرتبة، قابلة للتعديل
dict {"name": "سارة"} أزواج مفتاح/قيمة
tuple (1, 2, 3) قائمة غير قابلة للتعديل

اصطلاحات الأسماء

  • snake_case: user_name
  • حروف صغيرة فقط
  • أسماء وصفية لا مختصرة
  • لا كلمات محجوزة (if، for)

الثوابت

  • Python لا تفرض الثوابت
  • اصطلاح: UPPER_CASE
  • مثال: TAX_RATE = 0.05
  • المبرمج يحترم الاصطلاح

إعادة التعيين

  • المتغير يمكن أن يغيّر نوعه
  • x = 5 ثم x = "نص" مسموح
  • لكن قد يكون مربكاً — تجنّبه
  • يفضَّل احترام النوع طوال السكربت

bool

  • True وFalse بحرف كبير
  • true صغيرة خطأ
  • ليست نصاً بل نوع مستقل
  • تُستخدم في الشروط لاحقاً
خطأ شائع في اليوم الأول: كتابة true أو false بحروف صغيرة — هذه NameError في Python. الصواب True وFalse بحرف كبير.

الأرقام والنصوص والتحويل بين الأنواع

الأرقام في Python نوعان أساسيان: int للصحيح، float للكسور. العمليات الحسابية المعتادة تعمل مباشرة، مع إضافات لطيفة: القسمة الصحيحة //، الأس **، وباقي القسمة %.

numbers.py PYTHON 
a = 10
b = 3

print(a + b)         # 13 (جمع)
print(a - b)         # 7 (طرح)
print(a * b)         # 30 (ضرب)
print(a / b)         # 3.3333… (قسمة عادية → float دائماً)
print(a // b)        # 3 (قسمة صحيحة)
print(a % b)         # 1 (باقي القسمة)
print(a ** b)        # 1000 (الأس)

# دالة round للتقرير
print(round(3.14159, 2))   # 3.14
# دالة abs للقيمة المطلقة
print(abs(-7))             # 7

النصوص في Python لها واجهة غنية جداً: دمج، تحويل حالة، تقطيع، بحث. أهمها ما ستحتاجه في كل سكربت تقريباً:

strings.py PYTHON 
text = "  مرحباً بالعالم  "

# إزالة الفراغات من الطرفين
print(text.strip())              # "مرحباً بالعالم"

# تحويل الحالة
print(text.upper())              # "  مرحباً بالعالم  " (لا يؤثر على العربية)
print("Python".lower())           # "python"
print("python".capitalize())      # "Python"

# الاستبدال
print("hello world".replace("world", "Python"))

# التقسيم
words = "a, b, c".split(", ")
print(words)                      # ['a', 'b', 'c']

# الدمج
joined = "-".join(words)
print(joined)                     # "a-b-c"

# القياس
print(len("مرحباً"))              # 6

# الفهرسة والتقطيع
s = "Python"
print(s[0])                       # P
print(s[-1])                      # n
print(s[0:3])                     # Pyt
print(s[:3])                      # Pyt
print(s[3:])                      # hon

أما التحويل بين الأنواع فهو من أهم المهارات لأن مدخلات المستخدم تأتي دائماً نصوصاً، لكنك تحتاجها أرقاماً في الحساب:

conversions.py PYTHON 
# نص → رقم
n1 = int("42")           # 42
n2 = float("3.14")       # 3.14

# رقم → نص
s1 = str(42)             # "42"

# تحقق من النجاح
print(type(n1))          # <class 'int'>

# خطر: تحويل غير صالح
try:
    int("abc")           # ValueError
except ValueError:
    print("قيمة غير صالحة")

# تحويل بين int و float
print(int(3.99))         # 3 (يقتطع)
print(float(7))          # 7.0

# bool من قيمة أخرى
print(bool(0))           # False
print(bool(""))          # False
print(bool(None))        # False
print(bool(42))          # True
print(bool("0"))         # True (النص غير فارغ!)
قاعدة ذهبية: قبل أي عملية حسابية على مدخل مستخدم، حوّله إلى رقم مع تحقق. استخدم try/except ValueError بدل الثقة العمياء. التحويل بدون تحقق هو أحد أشهر أسباب تعطّل التطبيقات لاحقاً.

print و input و f-strings

print() تطبع 값을 على الطرفية، وinput() تقرأ سطراً من المستخدم. هما نافذة التواصل الأساسية في سكربتات اليوم. معاً، وبمساعدة f-strings، تصنع سكربتات محادثة تفاعلية.

io-basics.py PYTHON 
# print بسيطة
print("مرحباً")

# print بعدة قيم — تفصل بينها مسافة تلقائياً
print("الاسم:", "سارة", "— العمر:", 20)

# طباعة بدون سطر جديد في النهاية
print("بدون", end="")
print(" فصل")

# الطباعة بقيم مفصولة بفاصل مخصص
print("a", "b", "c", sep="-")       # a-b-c

# input ترجع دائماً نصاً
name = input("ما اسمك؟ ")
age_str = input("كم عمرك؟ ")
age = int(age_str)                   # تحويل إلى رقم

print(f"مرحباً {name}، عمرك {age} سنة")
نقطة حرجة: input() ترجع دائماً str. حتى لو كتب المستخدم 42، فالقيمة هي النص "42". إذا نسيت التحويل إلى int ثم حاولت إضافة رقم إليها، ستحصل على TypeError. حوّل دائماً قبل الحسابات.

f-strings لأنظف مخرجات

f-strings (formatted string literals) هي أوضح طريقة لتنسيق النصوص: ضع f قبل علامة الاقتباس، وأدخل قيم داخل {}. داخل الأقواس لا تضع متغيراً فقط، بل يمكنك وضع تعبير كامل.

fstrings.py PYTHON 
name = "سارة"
age = 20
price = 49.5

# دمج بسيط
print(f"مرحباً {name}، عمرك {age} سنة")

# تعبير حسابي داخل الأقواس
print(f"المجموع: {price * 2}")

# تنسيق الأرقام (2 خانة عشرية)
print(f"السعر: {price:.2f}")         # السعر: 49.50

# تنسيق الأرقام الكبيرة بفواصل
big = 1234567
print(f"{big:,}")                     # 1,234,567

# محاذاة النصوص
print(f"{'سارة':>10}")               # "     سارة"
print(f"{'سارة':<10}")               # "سارة     "
لماذا f-strings؟ لأن بدائلها القديمة (% و.format()) أثقل وأصعب قراءة. في Python 3.6+ صارت f-strings هي الأسلوب المفضّل، وفي المساق سنستخدمها دائماً.

القوائم والقواميس

القوائم والقواميس هما العمود الفقري لأي بيانات في Python. تقريباً كل شيء في Flask لاحقاً سيمر عبر قائمة أو قاموس: قائمة مستخدمين، قاموس إعدادات، قاموس طلب JSON.

القوائم (list)

قائمة مرتبة قابلة للتعديل، تُكتب بين [ ]، وتُفهرس من 0. تدعم التكرار والتقطيع وإضافة/حذف العناصر.

lists.py PYTHON 
skills = ["HTML", "CSS", "JavaScript", "Python"]

# الوصول بالفهرس
print(skills[0])              # HTML
print(skills[-1])             # Python

# الطول
print(len(skills))            # 4

# التقطيع
print(skills[1:3])            # ['CSS', 'JavaScript']

# إضافة
skills.append("Flask")        # في الأخير
skills.insert(0, "Git")       # في الأول

# حذف
skills.remove("CSS")          # بحسب القيمة
last = skills.pop()           # من الأخير

# البحث
print("Python" in skills)     # True
print(skills.index("Python")) # فهرس أول ظهور

# الفرز
numbers = [3, 1, 4, 1, 5, 9, 2]
numbers.sort()                # تصاعدي
numbers.sort(reverse=True)    # تنازلي
print(sorted(numbers))        # نسخة مفروزة دون تعديل الأصلية

# التكرار
for skill in skills:
    print("-", skill)

القواميس (dict)

القاموس سجل أزواج مفتاح/قيمة، يُكتب بين { }، ويُستخدم عندما تريد الوصول للقيمة عبر اسم لا عبر موقع. هو الوسيط القياسي للبيانات القادمة من/إلى JSON في Flask.

dicts.py PYTHON 
student = {
    "name": "سارة",
    "age": 20,
    "skills": ["HTML", "CSS", "Python"],
    "active": True
}

# الوصول
print(student["name"])             # سارة
print(student.get("age"))          # 20
print(student.get("missing"))      # None
print(student.get("missing", 0))   # 0 (قيمة افتراضية)

# الإضافة والتعديل
student["city"] = "غزة"
student["age"] = 21

# الحذف
del student["active"]

# المفاتيح والقيم
print(student.keys())     # dict_keys(['name', 'age', 'skills', 'city'])
print(student.values())   # dict_values([...])
print(student.items())    # dict_items([...])

# التكرار
for key, value in student.items():
    print(f"{key}: {value}")

print(len(student))       # عدد الأزواج

list vs dict

  • list: وصول بالفهرس (0,1,2…)
  • dict: وصول بالمفتاح ("name")
  • list: مرتبة دائماً
  • dict: غير مضمون الترتيب قبل Python 3.7

متى نستخدم كل واحدة

  • قائمة أسماء → list
  • سجل طالب واحد → dict
  • قائمة سجلات → list of dict
  • إعدادات التطبيق → dict

نقاط انتباه

  • فهرس قائمة غير موجود → IndexError
  • مفتاح قاموس غير موجود → KeyError
  • استخدم .get() للوصول الآمن
  • لا تعدّل قائمة أثناء المرور عليها

tip_calculator.py — نموذج البداية PYTHON 
# tip_calculator.py
print("=== حاسبة البقشيش ===")

try:
    bill = float(input("قيمة الفاتورة: "))
    tip_percent = float(input("نسبة البقشيش (%): "))
except ValueError:
    print("خطأ: يُرجى إدخال أرقام صحيحة.")
    exit(1)

if bill <= 0 or tip_percent < 0:
    print("خطأ: القيم يجب أن تكون موجبة.")
    exit(1)

tip = bill * tip_percent / 100
total = bill + tip

print(f"الفاتورة:   {bill:.2f}")
print(f"البقشيش:    {tip:.2f}")
print(f"المجموع:    {total:.2f}")
معيار الإنجاز: السكربتات الثلاثة تعمل بلا توقف عند مدخلات صحيحة، وتتعامل مع المدخلات الخاطئة بلا انهيار، والمخرجات بالعربية منسقة، والتحويلات معقولة. لا تحذيرات أو أخطاء عند التشغيل العادي.

أخطاء شائعة ونصائح

الإزاحة الخاطئة

Python تعتمد الإزاحة لتحديد الكتل. اختلاط Tab ومسافات، أو إزاحة سطر بسطر غير مناسب، يُنتج IndentationError. اضبط VS Code على 4 مسافات دائماً.

True/False صغيرة

true وfalse بحروف صغيرة خطأ. اكتب True وFalse بحرف كبير أولاً.

نسيان تحويل input

input() ترجع نصاً. كل عملية حسابية تحتاج int() أو float(). هذا أشهر سبب لـTypeError عند المبتدئين.

استخدام = بدل ==

if x = 5: خطأ نحوي. المُقارنة بـ==. هذا يتضح بسرعة من رسالة الخطأ.

تحويل بدون try/except

int("abc") يرفع ValueError ويوقف البرنامج. لفّ التحويلات في try/except عند التعامل مع مدخلات المستخدم.

مفتاح قاموس مفقود

d["missing"] يرفع KeyError. استخدم d.get("missing") عندما لا تتأكد من وجود المفتاح.

فهرس قائمة خارج النطاق

skills[10] في قائمة من 3 عناصر يرفع IndexError. تحقق من len() قبل الوصول بفهرس متغير.

تسمية ملف باسم مكتبة

إذا سمّيت ملفك random.py أو json.py، فسيحل محل المكتبة القياسية نفسها، وتحدث أخطاء غامضة. تجنّب ذلك.

نصائح ذهبية:
• اقرأ رسالة الخطأ كاملة — Python تشرح مكان الخطأ ونوعه.
• اطبع القيم قبل السطر الذي يفشل: print(type(x), x).
• ابدأ بالحالة البسيطة، ثم أضف التعقيد.
• شغّل السكربت من الطرفية، لا من داخل VS Code فقط.

ملخص المحاضرة

  • Python لغة برمجة تُستخدم في الويب والأمن وتحليل البيانات والأتمتة.
  • نستخدم Python 3.x حصراً، ونغلّف سكربتاتنا بحرفية وإزاحة صحيحة.
  • REPL للتجربة السريعة، وملفات .py للبرامج الحقيقية.
  • المتغيرات بلا تصريح نوع، بأسماء snake_case وصفية.
  • الأنواع المدمجة: str، int، float، bool، None، list، dict.
  • True وFalse بحرف كبير — لا صغيرة.
  • input() ترجع دائماً نصاً، وحوّلها إلى رقم قبل الحساب.
  • التحويل الآمن عبر try/except ValueError.
  • f-strings أفضل طريقة لتنسيق المخرجات: f"... {expr} ...".
  • القوائم لقوائم الأسماء والبيانات المتساوية، والقواميس للسجلات المفتاحية.
  • الوصول الآمن: d.get() للقاموس، وتحقّق من len() للقوائم.
  • كل قاعدة أمان في الواجهة يُعاد التحقق منها في الخادم — وهو دور Python لاحقاً.

تقييم سريع

1) ما الفرق بين REPL وملف السكربت؟

REPL وضع تفاعلي للتنفيذ الفوري سطر بسطر (لا يُحفظ)، ممتاز للتجربة. السكربت ملف .py يُحفظ ويُشغَّل كاملاً عبر python script.py، مناسب للبرامج الحقيقية والتسليمات.

2) ماذا ترجع input() وما نتيجتها على الحسابات؟

input() ترجع دائماً من نوع str، حتى لو كتب المستخدم رقماً. لذلك قبل أي عملية حسابية يجب تحويل النص: int() أو float()، مع لفّها في try/except ValueError.

3) ما الفرق بين القائمة والقاموس؟

القائمة list مرتبة وتُفهرس بأرقام ([0]، [1])، والقاموس dict سجل أزواج مفتاح/قيمة يُفهرس بالمفتاح (["name"]). القائمة للعناصر المتساوية، والقاموس للسجلات ذات السمات.

4) كيف نتعامل مع مدخل غير صالح عند التحويل إلى رقم؟

عبر try/except ValueError. نحاول التحويل داخل try، وفي except نطبع رسالة واضحة ونوقف التنفيذ برفق (أو نكرر الطلب). هذه أفضل من انهيار السكربت.

5) لماذا نستخدم f-strings؟

لأنها الأوضح والأقصر لتنسيق المخرجات. تسمح بإدراج متغيرات وتعابير داخل النص مباشرة: f"المجموع: {total:.2f}". بدائلها القديمة (% و.format()) أثقل قراءة.
