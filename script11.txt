[08:00 – 22:00] التحكم في التدفق: if / elif / else
============================================================

البرنامج الافتراضي ينفّذ من الأعلى إلى الأسفل.
لكن كل تطبيق حقيقي يحتاج قرارات.

الأداة الأولى: if.

if grade &gt;= 90:
    print("امتياز")

لاحظوا ثلاثة أشياء مهمة:
1. لا أقواس معقوفة.
2. لا أقواس حول الشرط (مثل JavaScript أو C).
3. النقطتان الرأسيتان : إلزاميتان.
4. الإزاحة إلزامية.

هذه الاختلافات الجذرية بين Python وبقية اللغات.
من اعتاد JavaScript، يحتاج تعوّداً يومياً.

الآن، عندنا حالة في، نستخدم elif و else:

if grade &gt;= 90:
    print("امتياز")
elif grade &gt;= 80:
    print("جيد جداً")
elif grade &gt;= 70:
    print("جيد")
elif grade &gt;= 60:
    print("مقبول")
else:
    print("راسب")

نقطة مهمة: ترتيب الشروط.
ابدأ بالأضيق، ثم الأوسع. لأن أول شرط يتحقق يوقف الفحص.
لو بدأت بـ&gt;= 60 قبل &gt;= 90، ستحصل على "مقبول" حتى لدرجة 95.

الآن العمليات المنطقية:
- and بدل &amp;&amp;
- or بدل ||
- not بدل !
- is للتحقق من الهوية (غالباً مع None)
- in للاحتواء

مثال:

if username and password and len(password) &gt;= 8:
    print("بيانات صالحة")
else:
    print("بيانات ناقصة")

ملاحظة: username في if يعني "if username غير فارغ".
هذا مفهوم truthy/falsy:
- Falsy: 0، ""، []، {}، None، False.
- Truthy: كل ما عدا ذلك (بما فيه "0").

هذا يسبب مفاجآت:
if "0": print("هذا صحيح!")     # يطبع!
if 0:  print("لن يطبع")         # لا يطبع

احترسوا من هذا عند التعامل مع مدخلات النماذج،
لأنها تأتي كنصوص.

أخيراً، التعبير الثلاثي:
status = "بالغ" if age &gt;= 18 else "قاصر"

هذا سطر واحد. مفيد للحالات البسيطة فقط.
لا تكتب شروطاً متداخلة.

[22:00 – 35:00] الحلقات: for
============================================================

الحلقة for في Python مختلفة عن JavaScript.
لا يوجد for (let i = 0; i &lt; n; i++).
بدلاً من ذلك:

for i in range(5):
    print(i)

range(5) تولّد تسلسلاً: 0 1 2 3 4.
هذا هو الشكل الأصلي في Python: التكرار على تسلسل.

أهم أشكال for:

1) for على قائمة:
skills = ["HTML", "CSS", "JS"]
for skill in skills:
    print(skill)

2) for على مدى:
for i in range(5):
    print(i)

3) for على نص:
for ch in "Python":
    print(ch)   # P y t h o n

4) for على قاموس (يمر على المفاتيح افتراضياً):
for key in student:
    print(key, "=", student[key])

5) مع enumerate (فهرس + قيمة):
for i, skill in enumerate(skills, start=1):
    print(f"{i}. {skill}")

6) مع zip (تزامن قائمتين):
names = ["سارة", "أحمد"]
ages = [20, 21]
for name, age in zip(names, ages):
    print(f"{name}: {age}")

أشكال range:
range(5)             # 0 1 2 3 4
range(2, 6)          # 2 3 4 5
range(0, 10, 2)      # 0 2 4 6 8
range(5, 0, -1)      # 5 4 3 2 1

ملاحظة: range لا ينشئ قائمة كاملة في الذاكرة،
بل يولّد عنصراً عند الحاجة. مفيد للأرقام الكبيرة.

[35:00 – 45:00] الحلقات: while و break و continue
============================================================

while يُستخدم عندما يعتمد التكرار على شرط،
وقد لا ينفّذ أبداً:

count = 0
while count &lt; 3:
    print("count =", count)
    count += 1

مفيد في:
- القوائم التفاعلية (قائمة حتى يختار المستخدم "خروج").
- القراءة حتى نهاية مدخل.
- أي حالة تعتمد على شرط متغير.

تحذير: احذروا الحلقات اللانهائية.
لو نسيت count += 1، سيبقى البرنامج يعمل.
في Python، أوقفوه بـCtrl+C في الطرفية.

الآن break و continue:

break — يخرج من الحلقة فوراً:

for n in range(10):
    if n == 5:
        break
    print(n)
# يطبع: 0 1 2 3 4

continue — يتخطى التكرار الحالي فقط:

for n in range(10):
    if n % 2 == 0:
        continue
    print(n)
# يطبع: 1 3 5 7 9

ميزة غريبة في Python: else بعد الحلقة.

numbers = [1, 2, 3, 4, 5]
target = 7

for n in numbers:
    if n == target:
        print("وجدت", target)
        break
else:
    print("لم أجد", target)

else تُنفّذ إذا انتهت الحلقة بدون break.
هذا يعني "لم أخرج قبل النهاية".
هي رديفة مثالية للبحث: إن لم تجد، else تُبلّغ.

لاحظوا: هذا الشكل لا يوجد في أغلب اللغات.
في JavaScript، كنت تحتاج متغير hasFound.
هنا، else تجعل الكود أنظف.

[45:00 – 55:00] القوائم والصفوف
============================================================

تحدثنا عن القوائم سابقاً. اليوم نعمّق وعينا.

تذكير بأهم الطرق:
- append(x): إضافة في النهاية.
- insert(i, x): إضافة في موضع.
- remove(x): حذف بالقيمة.
- pop(): حذف من النهاية (أو pop(i) من موضع).
- sort(): ترتيب (يعدّل الأصلية).
- sorted(): نسخة مرتّبة.
- reverse(): عكس الترتيب.
- index(x): موضع أول ظهور.
- count(x): عدد مرات الظهور.
- len(list): الطول.
- sum(list): المجموع (للأرقام).
- min / max: الحد الأدنى والأعلى.

نقطة مهمة: sort() تعدّل القائمة الأصلية،
sorted() تُرجع نسخة جديدة. هذا فرق جوهري.

أما tuple — الصف:
point = (3, 7)
هي قائمة لا يمكن تعديلها.
لا append، لا remove، لا sort.

لماذا نستخدم tuple؟
- إحداثيات (x, y).
- ثوابت (أيام الأسبوع).
- مفاتيح قاموس (list لا تصلح).
- إرجاع قيم متعددة من دالة:
  return min_val, max_val
  التي تُرجع tuple فعلياً.

تفكيك tuple:
x, y = point
a, b, c = (1, 2, 3)
هذا يعمل، وهو فعّال جداً.

مصيدة: tuple من عنصر واحد:
single = (42)   # هذا int!
correct = (42,) # هذا tuple

الفاصلة الزائدة ضرورية. type() يكشفها.

[68:00 – 78:00] List comprehensions
============================================================

هذه إحدى أجمل ميزات Python.

بدلاً من:
squares = []
for n in range(1, 6):
    squares.append(n * n)

الآن نكتب:
squares = [n * n for n in range(1, 6)]

سطر واحد بدل ثلاثة، وأكثر وضوحاً.
هذا هو List comprehension.

الشكل العام:
[Expression for item in iterable if condition]

أمثلة:

evens = [n for n in nums if n % 2 == 0]
uppers = [w.upper() for w in words]
lengths = [len(w) for w in words]
names = [s["name"] for s in students]
passed = [s for s in students if s["grade"] &gt;= 80]

ويمكن الاستخدام على dictionaries:
squares = {n: n * n for n in range(5)}

وعلى sets:
unique_lengths = {len(w) for w in words}

وهناك "تعبير مولّد" (generator)، بأقواس بدل مربعات:
total = sum(n * n for n in nums)

هذا لا ينشئ قائمة كاملة، بل يولّد عنصراً عند الحاجة.
مفيد للذاكرة.

تجنّبوا الـ comprehension عندما:
- يتجاوز التعبير سطراً.
- فيه شروط متداخلة.
- فيه منطق معقد.
في هذه الحالات، حلقة عادية أوضح.

[78:00 – 92:00] الدوال
============================================================

الدالة كتلة كود مسماة، تُنفَّذ عند الاستدعاء.

الشكل:
def greet(name):
    """دالة ترحيب"""
    return f"مرحباً {name}"

- def: كلمة تعريف الدالة.
- اسم_الدالة: بحروف صغيرة، snake_case.
- (name): المعاملات بين أقواس.
- :: إلزامية.
- """docstring""": توثيق اختياري.
- return: قيمة الإرجاع (اختياري).

مثال بلا return:
def show(x):
    print(x)

show("hi")   # يطبع hi، لكنه يُرجع None

مثال بـreturn:
def add(a, b):
    return a + b

result = add(5, 3)   # 8

الفرق بين print و return:
- print تطبع في الطرفية.
- return تُرجع قيمة للكود المستدعي.

هذا فرق حاسم. من يخلط بينهما يقول "دالتي لا تعمل".
الواقع: هي تعمل، لكنك لا تستخدم الناتج.

القيم الافتراضية:
def greet(name="زائر"):
    return f"مرحباً {name}"

greet()         # مرحباً زائر
greet("سارة")   # مرحباً سارة

المعاملات المفتاحية:
register(name="سارة", email="s@x.com", age=25)

مرونة أكبر، وأوضح في القراءة عندما يكون للدالة 4+ معاملات.

عدد متغير من المعاملات:
def total(*numbers):
    return sum(numbers)

total(1, 2, 3)        # 6
total(10, 20, 30, 40) # 100

*numbers يجمع كل المعاملات في tuple.

و**kwargs:
def show_info(**info):
    for k, v in info.items():
        print(k, v)

show_info(name="سارة", age=20)

**info يجمع في dict.

النطاق (Scope):
- متغيرات داخل الدالة: local، لا تخرج.
- متغيرات خارجها: global، متاحة للقراءة.
- لتعديل global: تحتاج global keyword، لكن يفضّل تجنّبها.

القاعدة الذهبية للدوال:
- كل دالة تفعل شيئاً واحداً.
- اسمها يصف ما تفعله.
- معاملاتها واضحة.
- return صريح.
- docstring قصير.

[92:00 – 108:00] try/except/else/finally
============================================================

الأخطاء جزء طبيعي. try/except تمنع الانهيار.

الشكل الأساسي:

try:
    age = int("abc")
except ValueError:
    print("قيمة غير صالحة")

الأجزاء:

try:
    # كود قد يفشل
except SomeException:
    # معالجة الخطأ
else:
    # ينفَّذ إذا لم يحدث خطأ
finally:
    # ينفَّذ دائماً

تفاصيل مهمة:

1) استثناءات متعددة:
except ValueError:
    ...
except (TypeError, KeyError):
    ...

2) كائن الخطأ:
except ValueError as e:
    print(e)

3) else — بعد try الناجح:
try:
    x = int("42")
except ValueError:
    print("فشل")
else:
    print(f"نجح: {x}")

4) finally — دائماً:
finally يُنفَّذ سواء حدث خطأ أو لا.
استخدامه الأبرز: تحرير موارد (إغلاق ملف، اتصال، إلخ).

5) raise — إعادة رفع:
except ValueError:
    print("سجّل الخطأ")
    raise

الاستثناءات الشائعة التي ستراها:
- ValueError: قيمة غير صالحة للتحويل.
- TypeError: نوع غير مناسب للعملية.
- KeyError: مفتاح قاموس مفقود.
- IndexError: فهرس قائمة خارج النطاق.
- ZeroDivisionError: قسمة على صفر.
- FileNotFoundError: ملف مفقود.
- AttributeError: خاصية مفقودة.

تحذير مهم:
لا تستخدم except Exception: عشوائياً.
هذا يلتقط حتى الأخطاء البرمجية (مثل خطأ إملائي في اسم
متغير) ويخفيها، فيصعب التشخيص.
التقط فقط ما تتوقعه.

قاعدة عملية:
- تحقق "متوقع" → if/raise.
- خطأ "غير متوقع" → try/except.
- لا تخلط بينهما.

[118:00 – 140:00] التطبيق العملي

الآن التطبيق. ثلاث سكربتات.

السكربت الأول: عدّاد كلمات.
الخطوات:
- اطلب نصاً من المستخدم.
- قسّمه بـsplit().
- احسب تكرار كل كلمة بـdict.
- رتبهم تنازلياً.
- اطبع أكثر 5 كلمات.

النمط الأساسي:

def count_words(text):
    if not isinstance(text, str):
        raise TypeError("يجب تمرير نص")
    freq = {}
    for word in text.split():
        key = word.strip().lower()
        if not key:
            continue
        freq[key] = freq.get(key, 0) + 1
    return freq

لاحظوا:
- فحص النوع في البداية (raise).
- get(key, 0) للتعامل مع المفاتيح المفقودة.
- continue لتخطي الكلمات الفارغة.

السكربت الثاني: مخزون بسيط.
- قائمة من dicts.
- دوال: add_item، update_qty، total_value.
- استخدام .get() وraise للأخطاء.

السكربت الثالث: دفتر جهات اتصال.
- قاموس: {"name": "+970-xxx"}.
- دوال: add_contact، delete_contact، search.
- تحقق من صيغة الهاتف.

لاحظوا النمط المشترك:
- كل سكربت له دالة main().
- كل سكربت له if __name__ == "__main__":.
- الدوال المشتركة في utils.py.
- استيراد واضح: from utils import ...

هذا النمط هو نفسه الذي سنراه في Flask.

[140:00 – 148:00] أخطاء شائعة

دعونا نمرّ على الأخطاء:
