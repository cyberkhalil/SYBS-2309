التحكم في التدفق: if / elif / else

البرنامج الافتراضي ينفّذ سطرًا بعد سطر. عندما نضيف شروطًا، يبدأ بالتفكير: "إن تحقّق كذا افعل كذا، وإلا إن تحقّق كذا افعل كذا، وإلا افعل الافتراضي". هذه هي أداة التحكم في التدفق. فرقها الرئيسي عن JavaScript أن الإزاحة إلزامية، ولا توجد أقواس معقوفة للكتل.

if-basic.py PYTHON 
grade = 85

if grade >= 90:
    print("امتياز")
elif grade >= 80:
    print("جيد جداً")
elif grade >= 70:
    print("جيد")
elif grade >= 60:
    print("مقبول")
else:
    print("راسب")

# الناتج: جيد جداً

المقارنة

  • ==، !=
  • <، <=
  • >، >=
  • in للاحتواء
  • is للتحقق من الهوية (غالباً مع None)

المنطق

  • and (بدل &&)
  • or (بدل ||)
  • not (بدل !)
  • الكلمات نفسها لا الرموز

Truthy / Falsy

  • Falsy: 0، ""، []، {}، None، False
  • كل ما عدا ذلك Truthy
  • مثل JavaScript تماماً
  • احترس من "0" (نص غير فارغ = Truthy)

أخطاء شائعة

  • استخدام = بدل ==
  • نسيان : في نهاية الشرط
  • إزاحة غير متسقة
  • ترتيب الشروط من الأصغر للأكبر (خطأ)
ترتيب الشروط مهم: ابدأ دائمًا بالشرط الأكبر/الأضيق. لأن أول شرط يتحقق يوقف الفحص. لو بدأت بـ>= 60 قبل >= 90، سيعطي "مقبول" حتى لدرجة 95.

التعبير الثلاثي (Ternary)

إذا كانت الحالة بسيطة (نعم/لا)، يمكن استخدام صيغة قصيرة في سطر واحد: قيمة_إن_تحقق if الشرط else قيمة_إن_لم_يتحقق.

ternary.py PYTHON 
age = 20
status = "بالغ" if age >= 18 else "قاصر"
print(status)   # بالغ

# مفيد في القيم الافتراضية
name = input("اسمك؟ ").strip()
display = name if name else "زائر"
print(f"مرحباً {display}")

match — بديل switch (Python 3.10+)

في Python 3.10+ هناك match الذي يشبه switch في لغات أخرى، لكنه أقوى. لن نعتمد عليه كثيرًا، لكن من الجيد معرفته.

match.py PYTHON 
day = "الجمعة"

match day:
    case "السبت" | "الأحد" | "الاثنين" | "الثلاثاء" | "الأربعاء" | "الخميس":
        print("يوم عمل")
    case "الجمعة":
        print("نهاية الأسبوع")
    case _:
        print("قيمة غير معروفة")
قاعدة عملية: استخدم if/elif/else في 99% من الحالات. استخدم match فقط إذا كنت على Python 3.10+ وكان لديك مطابقة بنيوية معقدة. لا تعقّد كودك بلا سبب.

الحلقات: for و while

الحلقات تكرّر كتلة كود. Python تقدّم شكلين أساسيين: for للتكرار على تسلسل، وwhile للتكرار بحسب شرط.

for

  • للتكرار على تسلسل (قائمة، نص، مدى)
  • لا تحتاج فهرسًا في الغالب
  • مع range() نولّد أرقامًا
  • مع enumerate() نحصل على فهرس وقيمة

while

  • للتكرار بحسب شرط
  • قد ينفّذ صفر مرة
  • احترس من الحلقات اللانهائية
  • يحتاج شيئًا يقرّب الشرط من الانتهاء

break وcontinue

  • break يخرج من الحلقة
  • continue يتخطى التكرار الحالي
  • لا يعملان مع else بشكل غير متوقع
  • كلاهما يوقفان الدورة الحالية

else في الحلقات

  • ميزة Python غير موجودة في لغات أخرى
  • تُنفّذ بعد انتهاء الحلقة بدون break
  • مفيدة للبحث
  • "لم أجد العدد" تُكتب في else
loops.py PYTHON 
# 1) for على مدى
for i in range(5):
    print(i)        # 0 1 2 3 4

# 2) for على قائمة
skills = ["HTML", "CSS", "JavaScript"]
for skill in skills:
    print("-", skill)

# 3) مع enumerate (فهرس + قيمة)
for i, skill in enumerate(skills, start=1):
    print(f"{i}. {skill}")

# 4) while
count = 0
while count < 3:
    print("count =", count)
    count += 1

# 5) break
for n in range(10):
    if n == 5:
        break
    print(n)        # 0 1 2 3 4

# 6) continue
for n in range(10):
    if n % 2 == 0:
        continue
    print(n)        # 1 3 5 7 9

# 7) else في حلقة for — للبحث
numbers = [1, 2, 3, 4, 5]
target = 7

for n in numbers:
    if n == target:
        print("وجدت", target)
        break
else:
    print("لم أجد", target)

القوائم والصفوف (list وtuple)

في المحاضرة 10 تعرّفنا على القوائم. اليوم نتعمق أكثر، ونضيف التوبلز. الفرق الجوهري: القائمة قابلة للتعديل (mutable)، والصف غير قابل للتعديل (immutable). اختيار النوع الصحيح يحمي بياناتك من التعديل غير المقصود.

الخصيصة list tuple
البنية [1, 2, 3] (1, 2, 3)
قابلة للتعديل نعم لا
الاستخدام قوائم متغير المحتوى أزواج ثابتة، إحداثيات، نتائج دوال متعددة
الأداء مرن أسرع قليلًا
الاستخدام كمفتاح قاموس لا (غير قابل للتجزئة) نعم، إذا كانت عناصره غير قابلة للتعديل
lists-tuples.py PYTHON 
# ===== القوائم =====
numbers = [3, 1, 4, 1, 5, 9, 2]

numbers.append(6)        # في النهاية
numbers.insert(0, 0)     # في البداية
numbers.remove(1)        # بحسب القيمة
last = numbers.pop()     # من النهاية

numbers.sort()           # تصاعديًا
numbers.sort(reverse=True)  # تنازليًا
sorted(numbers)          # نسخة دون تعديل الأصلية
numbers.reverse()        # عكس الترتيب

print(len(numbers))
print(sum(numbers))
print(min(numbers))
print(max(numbers))

# البحث
print(4 in numbers)          # True/False
print(numbers.index(4))      # موضع أول ظهور
print(numbers.count(1))      # عدد مرات الظهور

# ===== الصفوف =====
point = (3, 7)
x, y = point                 # تفكيك
print(x, y)                  # 3 7

rgb = (255, 128, 0)

# محاولة التعديل — خطأ
# rgb[0] = 0                 # TypeError

# صف من عنصر واحد — لاحظ الفاصلة
single = (42,)
not_tuple = (42)             # int، وليس tuple!

print(type(single))          # tuple
print(type(not_tuple))       # int

# دالة تُرجع صفًا
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4, 1, 5])
print(low, high)             # 1 5
متى نستخدم tuple؟ عندما تكون لديك بيانات لا يجب أن تُعدَّل: إحداثيات، قيم ثابتة، مفاتيح قاموس. وأيضًا لتفكيك نتائج دوال متعددة القيم: return min, max.
مصيدة tuple من عنصر واحد: (42) هو int وليس tuple. الصحيح: (42,) — بفاصلة زائدة. هذا خطأ شائع جدًا، والـ type() يكشفه فورًا.

القواميس والمجموعات (dict وset)

القاموس هو قلب أي تطبيق Flask: كل استجابة JSON هي قاموس، وكل سجل (مستخدم، منتج، ملاحظة) هو قاموس. المجموعة (set) أقل شيوعًا لكنها ممتازة للتحقق من العضوية وإزالة التكرار.

dicts.py PYTHON 
student = {
    "name": "سارة",
    "age": 20,
    "skills": ["HTML", "CSS", "Python"],
    "active": True
}

# الوصول
print(student["name"])              # سارة
print(student.get("age"))           # 20
print(student.get("missing"))       # None
print(student.get("missing", 0))    # 0

# الإضافة والتعديل
student["city"] = "غزة"
student["age"] = 21

# الحذف
del student["active"]
removed = student.pop("city")

# المرور على المفاتيح والقيم
for key in student:
    print(key, "=", student[key])

for key, value in student.items():
    print(f"{key}: {value}")

# تحديث دفعة واحدة
student.update({"city": "غزة", "email": "sara@example.com"})

# الدمج
extra = {"major": "أمن معلومات"}
student.update(extra)

# نسخة (shallow)
copy1 = student.copy()

# القائمة من القواميس هي "جدول" في الذاكرة
students = [
    {"name": "سارة", "age": 20, "grade": 88},

    {"name": "ليلى", "age": 19, "grade": 92},
]

# البحث
for s in students:
    if s["name"] == "أحمد":

passed = [s for s in students if s["grade"] >= 80]

by_grade = sorted(students, key=lambda s: s["grade"], reverse=True)

sets.py PYTHON 
# مجموعة: بلا ترتيب، بلا تكرار
tags = {"html", "css", "js", "html"}
print(tags)               # {"html", "css", "js"}

# إضافة وحذف
tags.add("python")
tags.discard("css")       # لا يرفع خطأ إذا لم يوجد
tags.remove("js")         # يرفع KeyError إذا لم يوجد

# التحقق
print("html" in tags)     # True

# عمليات المجموعات
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)              # اتحاد    → {1,2,3,4,5,6}
print(a & b)              # تقاطع    → {3,4}
print(a - b)              # فرق      → {1,2}
print(a ^ b)              # فرق متماثل → {1,2,5,6}

# إزالة التكرار من قائمة
nums = [1, 2, 2, 3, 3, 3, 4]
unique = list(set(nums))
print(unique)             # [1, 2, 3, 4] (الترتيب غير مضمون)
متى نستخدم set؟ عندما نحتاج "هل هذا العنصر موجود؟" بسرعة. البحث في set فوري تقريبًا (O(1))، بينما البحث في list يتطلب المرور على العناصر (O(n)). للقوائم الكبيرة، استخدم set.

List comprehensions

هذه إحدى أجمل ميزات Python. بدلًا من حلقة وappend، تستطيع كتابة العملية كاملة في سطر واحد. مفيدة جدًا لتحويل أو تصفية القوائم.

comprehensions.py PYTHON 
# ===== الطريقة التقليدية =====
nums = [1, 2, 3, 4, 5, 6]
squares = []
for n in nums:
    squares.append(n * n)

print(squares)   # [1, 4, 9, 16, 25, 36]

# ===== List comprehension =====
squares = [n * n for n in nums]
print(squares)

# ===== مع شرط =====
evens = [n for n in nums if n % 2 == 0]
print(evens)     # [2, 4, 6]

# ===== نصوص =====
words = ["hello", "world", "python"]
upper = [w.upper() for w in words]
print(upper)     # ['HELLO', 'WORLD', 'PYTHON']

lengths = [len(w) for w in words]
print(lengths)   # [5, 5, 6]

# ===== على قاموس =====
students = [
    {"name": "سارة", "grade": 88},
    {"name": "أحمد", "grade": 74},
    {"name": "ليلى", "grade": 92},
]

names = [s["name"] for s in students]
passed = [s for s in students if s["grade"] >= 80]

# ===== Dict comprehension =====
squares_dict = {n: n * n for n in range(5)}
print(squares_dict)   # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# ===== Set comprehension =====
unique_lengths = {len(w) for w in words}
print(unique_lengths)   # {5, 6}

# ===== تعبير مولد (generator) — أقواس بدل مربعات =====
total = sum(n * n for n in nums)
print(total)   # 91
متى نتجنّبها؟ عندما يتجاوز التعبير سطرًا واحدًا، أو يحتوي شروطًا متداخلة، أو منطقًا معقدًا. في هذه الحالة، حلقة عادية مع تعليقات أوضح للقراءة. Comprehension أداة للوضوح، لا للتباهي.

الدوال: المعاملات وreturn والنطاق

الدالة كتلة كود مسماة، تُستدعى عند الحاجة. هدفها الأول: عدم التكرار. هدفها الثاني: جعل الكود مفهومًا. في Flask، كل مسار (route) هو دالة. لذا إتقان الدوال شرط أساسي.

functions-basic.py PYTHON 
# 1) دالة بسيطة
def greet():
    print("مرحباً")

greet()

# 2) دالة بمعاملات
def greet_user(name):
    print(f"مرحباً {name}")

greet_user("سارة")

# 3) دالة تُرجع قيمة
def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8

# 4) return يوقف التنفيذ
def check_age(age):
    if age < 0:
        return "عمر غير صالح"
    if age >= 18:
        return "بالغ"
    return "قاصر"

print(check_age(20))
print(check_age(15))
print(check_age(-1))

# 5) دالة بلا return ترجع None
def show(x):
    print(x)

print(show("hi"))   # hi ثم None

def calculate_total(prices, tax_rate=0.15):
    """
    تحسب الإجمالي مع الضريبة.

    المعاملات:
        prices (list): قائمة الأسعار
        tax_rate (float): نسبة الضريبة، افتراضيًا 0.15

    الإرجاع:
        float: الإجمالي بعد الضريبة
    """
    if not prices:
        return 0.0

    subtotal = sum(prices)
    tax = subtotal * tax_rate
    return round(subtotal + tax, 2)


# الاستخدام
print(calculate_total([100, 200]))              # 345.0
print(calculate_total([100, 200], 0.20))        # 360.0
print(calculate_total([]))                      # 0.0

معالجة الاستثناءات try/except/else/finally

في Python، الأخطاء "استثناءات" (Exceptions). إذا لم نعالجها، البرنامج يتوقف ويعرض Traceback. try/except تسمح لنا بالتقاط الخطأ والتعامل معه. وelse وfinally يوسّعان التحكم.

try-except.py PYTHON 
# 1) الأساسي
try:
    age = int("abc")
except ValueError:
    print("قيمة غير صالحة")

# 2) استثناءات متعددة
try:
    numbers = [1, 2, 3]
    print(numbers[10])
    x = 1 / 0
except IndexError:
    print("فهرس خارج النطاق")
except ZeroDivisionError:
    print("قسمة على صفر")

# 3) عدة استثناءات في except واحد
try:
    value = int(input("رقم: "))
    result = 10 / value
except (ValueError, ZeroDivisionError):
    print("مدخل غير صالح أو صفر")

# 4) كائن الخطأ
try:
    int("abc")
except ValueError as e:
    print(f"الخطأ: {e}")

# 5) else — يُنفَّذ إذا لم يحدث خطأ
try:
    x = int("42")
except ValueError:
    print("فشل التحويل")
else:
    print(f"نجح: {x}")

# 6) finally — يُنفَّذ دائمًا
try:
    x = int("hello")
except ValueError:
    print("خطأ")
finally:
    print("انتهت المحاولة")   # يُطبع في كل الحالات

# 7) إعادة رفع الاستثناء
try:
    x = int("abc")
except ValueError:
    print("سجّل الخطأ")
    raise    # يعيد رفعه للمستوى الأعلى
الاستثناء متى يحدث كيف نتجنّبه
ValueError قيمة غير صالحة للتحويل try/except
TypeError عملية غير مناسبة للنوع تحقق من النوع
IndexError فهرس قائمة خارج النطاق تحقق من len()
KeyError مفتاح قاموس مفقود استخدم .get()
ZeroDivisionError قسمة على صفر تحقق قبل القسمة
FileNotFoundError ملف غير موجود try/except أو os.path.exists
AttributeError خاصية غير موجودة تحقق من النوع
لا تلتقط Exception عشوائيًا: except Exception: يلتقط كل شيء، حتى الأخطاء البرمجية التي يجب أن تظهر. القاعدة: التقِط الاستثناءات التي تتوقعها فقط: ValueError، KeyError، إلخ. هذا يجعل تشخيص الأخطاء أسهل بكثير.

def is_valid_email(value):
    if not isinstance(value, str):
        return False
    if "@" not in value:
        return False
    parts = value.split("@")
    if len(parts) != 2:
        return False
    if not parts[0] or not parts[1]:
        return False
    if "." not in parts[1]:
        return False
    return True


def is_positive_number(value):
    try:
        n = float(value)
    except (TypeError, ValueError):
        return False
    return n > 0

word_counter.py — نموذج البداية PYTHON 
def count_words(text):
    if not isinstance(text, str):
        raise TypeError("يجب تمرير نص")

    words = text.split()
    freq = {}
    for word in words:
        key = word.strip().lower()
        if not key:
            continue
        freq[key] = freq.get(key, 0) + 1

    return freq


def top_n(freq, n=5):
    return sorted(freq.items(), key=lambda x: x[1], reverse=True)[:n]


def main():
    try:
        text = input("أدخل نصًا: ")
    except KeyboardInterrupt:
        print("\nتم الإلغاء")
        return

    freq = count_words(text)

    if not freq:
        print("لم تُدخل أي كلمات.")
        return

    print(f"عدد الكلمات: {len(freq)}")
    print("الأكثر تكرارًا:")
    for word, count in top_n(freq):
        print(f"  {word} → {count}")


if __name__ == "__main__":
    main()

تقييم سريع

1) ما الفرق بين for وwhile؟

for للتكرار على تسلسل معروف الطول (قائمة، مدى، نص). while للتكرار بحسب شرط قد لا يتحقق أبدًا (ينفّذ صفر مرة). كلتاهما تدعمان break وcontinue.

2) ما وظيفة else بعد الحلقة؟

تُنفّذ بعد انتهاء الحلقة بشكل طبيعي، أي بدون حدوث break. مفيدة جدًا للبحث: إذا وجدت العنصر تُنفّذ break ولا تُنفّذ else، وإلا تُنفّذ else "لم أجد".

3) متى نستخدم tuple بدلًا من list؟

عندما تكون البيانات ثابتة (إحداثيات، ثوابت)، أو عندما نريد كفاءة أعلى قليلًا، أو عندما نحتاجها كمفتاح قاموس (لأنها قابلة للتجزئة). أيضًا لتفكيك قيم متعددة من دالة.

4) لماذا نستخدم try/except ولماذا لا نستخدم except Exception دائمًا؟

try/except يحمي البرنامج من الانهيار عند الأخطاء المتوقعة. لكن except Exception يلتقط حتى الأخطاء البرمجية (مثل خطأ إملائي في اسم متغير) ويخفيها، فيصعب التشخيص. الأفضل: التقاط فقط ValueError، KeyError، إلخ.

5) ما وظيفة if __name__ == "__main__":؟

تسمح بتشغيل الكود فقط عندما يُنفَّذ الملف مباشرة (python script.py)، وليس عند استيراده من وحدة أخرى. هذا يفصل "سلوك التنفيذ المباشر" عن "الدوال القابلة للاستيراد".
