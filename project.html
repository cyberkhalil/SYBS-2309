المشروع النهائي: بناء تطبيق ويب متكامل

تصميم وبرمجة الويب — HTML · CSS · JavaScript · Python Flask

تعليمات المشروع

هذا المشروع النهائي يهدف إلى بناء تطبيق ويب متكامل يجمع بين الواجهة الأمامية التي تعلّمتها في المرحلة الأولى (HTML · CSS · JavaScript) والواجهة الخلفية باستخدام Python وFlask. يجب تنفيذ التطبيق، توثيقه، واختباره، ثم تعبئة هذه الصفحة وتحميلها كملف PDF وتقديمها.

  • الدرجة: 30% من التقييم النهائي.
  • العمل: فردي (أو حسب تعليمات المحاضر).
  • المتطلبات: Python 3، Flask، VS Code، متصفح حديث.
  • هام: أدخل الاسم والرقم الجامعي ثم اضغط «بدء المشروع» لتمكين الإجابة.
  • التسليم: ملف PDF + ملفات المشروع (بدون مجلد venv).
المشروع مقفل. أدخل الاسم والرقم الجامعي ثم اضغط «بدء المشروع».

المهمة 1: فكرة المشروع والتخطيط

اختر فكرة تطبيق ويب بسيطة لكن متكاملة: ملاحظات، مهام، مخزون، جهات اتصال، حجز مواعيد، أو أي فكرة مناسبة. يجب أن تحتوي على عمليات إضافة وعرض وتعديل وحذف (CRUD) أو ما يعادلها.

سؤال 1: صف فكرة تطبيقك في 3–5 أسطر: ما المشكلة التي يحلها؟ من الجمهور المستهدف؟

سؤال 2: اذكر 4 ميزات أساسية و2 ميزات إضافية في التطبيق.

ارفع صورة مخطط الصفحات أو هيكل ملفات المشروع
اسحب وأفلت الصورة هنا أو انقر للاختيار

المهمة 2: الواجهة الأمامية — HTML الدلالي والوصولية

يجب أن تحتوي صفحاتك على بنية HTML دلالية: header، nav، main، section، footer، مع تسميات label للنماذج، ونص alt للصور.

سؤال 3: اشرح كيف حققت الدلالة والوصولية في صفحتين على الأقل من مشروعك (اذكر عناصر محددة).

ارفع صورة لصفحة HTML أو لتبويب Elements يوضح البنية الدلالية

المهمة 3: CSS المتجاوب والتخطيط

استخدم Flexbox و/أو Grid، ووحدات مناسبة (rem، %، fr)، وMedia Queries بأسلوب Mobile-first.

سؤال 4: اذكر نقاط التوقف (breakpoints) التي استخدمتها، ولماذا اخترتها؟

سؤال 5: (اختر الإجابة الصحيحة) أي وصف يطابق تصميمًا متجاوبًا سليمًا؟

استخدام عرض ثابت 1200px لكل الصفحات.
البدء بتصميم الهاتف ثم إضافة قواعد @media (min-width) للشاشات الأكبر.
إخفاء مؤشر التركيز outline دائمًا لتحسين الشكل.
استخدام الجداول لتخطيط الصفحة بدل CSS.
ارفع صورة للصفحة على الهاتف وصورة على الحاسوب

المهمة 4: JavaScript وDOM والأحداث

استخدم JavaScript لإضافة تفاعل حقيقي: addEventListener، تعديل DOM، تحقق من نموذج، أو إظهار/إخفاء عناصر.

سؤال 6: اشرح تفاعلًا واحدًا نفذته بـaddEventListener، وما المشكلة التي يحلها؟

سؤال 7: أين استخدمت e.preventDefault() ولماذا؟

ارفع صورة لتفاعل JavaScript أو لـConsole يظهر النتيجة

المهمة 5: Flask — البنية والمسارات

يجب أن يعمل التطبيق عبر Flask، وأن يحتوي على عدة مسارات واضحة.

python -m venv venv
venv\Scripts\activate   # Windows
source venv/bin/activate  # macOS / Linux
pip install flask
flask run

المهمة 6: قوالب Jinja ووراثة القوالب

استخدم render_template، وextends، وblock، وinclude حيث يلزم. اربط ملفات CSS وJS عبر url_for.

سؤال 9: اشرح كيف استخدمت extends وblock و/أو include لتقليل تكرار HTML.

سؤال 10: لماذا لا يُستخدم |safe مع مدخلات المستخدم في Jinja؟

ارفع صورة لملف قالب أو لصفحة تعمل عبر Flask

المهمة 7: النماذج والتحقق في الخادم وFlash

يجب أن يستقبل التطبيق بيانات من نموذج، يتحقق منها في الخادم، ويعرض رسالة نجاح أو خطأ باستخدام flash.

سؤال 11: اذكر حقلين في نموذجك، وقاعدة التحقق في الخادم لكل منهما، ورسالة الخطأ التي تظهر.

ارفع صورة لرسالة Flash ناجحة وأخرى لرسالة خطأ

المهمة 8: تخزين البيانات وعمليات CRUD

استخدم تخزينًا مناسبًا: قائمة في الذاكرة، أو ملف JSON، أو SQLite. يجب أن تستطيع إضافة عنصر، عرضه، تعديله، وحذفه.

سؤال 12: اشرح كيف تخزّن البيانات، وكيف نفّذت الإضافة/العرض/التعديل/الحذف.

ارفع صورة تعرض إضافة عنصر أو حذفه أو تعديله

المهمة 9: الأمان والاختبار

طبّق أساسيات الأمان: تحقق في الخادم، تهريب تلقائي عبر Jinja، عدم استخدام |safe مع مدخلات المستخدم، وتعطيل debug في ملف التسليم النهائي.

سؤال 13: اذكر إجراءين أمنيين طبّقتهما، واشرح فائدتهما.

سؤال 14: اذكر حالتي اختبار: مدخل صحيح ومدخل خاطئ، وماذا حدث في كل حالة.

ارفع صورة لرسالة خطأ أو لاختبار مدخل غير صالح

المهمة 10: التشغيل والتوثيق والتسليم

اكتب خطوات التشغيل من الصفر، وتأكد من وجود requirements.txt وREADME.md.

سؤال 15: اكتب خطوات تشغيل المشروع من الصفر (venv، تثبيت المكتبات، التشغيل).

قائمة التحقق قبل التسليم:

ملف requirements.txt موجود وناتج عن pip freeze.
ملف README.md يشرح طريقة التشغيل.
جميع الروابط الداخلية تستخدم url_for.
لا يوجد |safe على أي مدخل من المستخدم.
تم اختبار حالة صحيحة وحالة خاطئة على الأقل.
تم تعطيل debug=True في ملف التسليم النهائي.
pip freeze > requirements.txt
pip install -r requirements.txt
ارفع صورة لـREADME أو لطرفية التشغيل أو لملف requirements.txt

انتهت مهام المشروع
