منهجية المساق: تُبنى المرحلة الأولى على أساسيات الواجهة الأمامية — HTML5 الدلالي، CSS3 المتجاوب، وJavaScript التفاعلي — مع تطبيق عملي قصير كل أسبوع. تنتقل المرحلة الثانية إلى تطوير جهة الخادم، بتقديم أساسيات Python وبناء تطبيقات ويب باستخدام Flask، وتنتهي بـمشروع متكامل. يُقدَّم المحتوى من خلال محاضرات قصيرة ومختبر موجّه، والتعلّم قائم على المشروع ويُركّز على الكود النظيف والاختبار والتسليمات التدريجية.

مستند HTML5 · النصوص · الروابط · الصور · القوائم

مخرجات التعلم

  • بناء مستند HTML5 سليم
  • استخدام العناوين والفقرات والوسوم الدلالية بشكل صحيح
  • إدراج الروابط والصور والقوائم المرتبة وغير المرتبة

  • أفضل ممارسات التنسيق والتعليقات
التطبيق العملي: أنشئ صفحة ملف شخصي بعناوين مناسبة، صورة شخصية، قائمة مهارات، ورابط إلى موقعك المفضل.
الأسبوع 3

HTML المتقدم — الجداول والنماذج

نظري + عملي المحاضرة 3
الجداول · عناصر النماذج · الوصولية · الدلالة

مخرجات التعلم

  • إنشاء جداول قابلة للوصول باستخدام <thead>، <tbody>، <caption>
  • بناء نماذج تحتوي حقول إدخال، labels، selects، textareas، أزرار
  • اختيار أنواع حقول HTML5 المناسبة (email, password, number, date …)
  • تطبيق مبادئ الوصولية الأساسية (التسميات، التنقل بلوحة المفاتيح)

أساسيات النماذج

  • action وmethod (نظرة عامة GET مقابل POST)
  • التحقق في HTML5: required، pattern، minlength
  • تجميع الحقول بـ <fieldset> و<legend>
  • معالم دلالية: <header>، <nav>، <main>، <footer>
التطبيق العملي: أنشئ نموذج تسجيل أو تواصل مع تسميات مناسبة، تجميع للحقول، وسمات تحقق HTML5.
الأسبوع 4

أساسيات CSS — المحددات ونموذج الصندوق والطباعة

نظري + عملي المحاضرة 4
محددات CSS3 · نموذج الصندوق · الألوان · الخطوط

مخرجات التعلم

  • ربط CSS بـ HTML بثلاث طرق (خارجي، داخلي، ضمني)
  • استخدام محددات العنصر والصنف والمعرّف والمحددات المتداخلة
  • تطبيق الألوان والخطوط والخلفيات على عناصر التخطيط
  • استيعاب نموذج الصندوق (المحتوى، الحشو، الحد، الهامش)

مفاهيم أساسية

  • الخطوط: font-family، font-size، line-height
  • الخلفيات: ألوان، صور، تدرجات
  • الحدود: border، border-radius، box-shadow
  • قواعد التخصيص (Specificity) والوراثة
التطبيق العملي: نسّق صفحة HTML متعددة الأقسام — أضف ألواناً وخطوطاً ومسافات وحدوداً تحسّن قابلية القراءة.

التخطيط والتصميم المتجاوب

نظري + عملي المحاضرة 5
Flexbox · مقدمة إلى Grid · وحدات القياس · Media Queries

مخرجات التعلم

  • الاختيار بين Flexbox وGrid حسب سيناريو التخطيط
  • استخدام وحدات مثل px، %، rem، em، vh/vw

  • display: grid مع grid-template-columns وgap
  • نقاط توقف شائعة (480، 768، 1024)
  • اختبار التخطيطات في وضع الأجهزة بأدوات المطور
التطبيق العملي: ابنِ صفحة متجاوبة بعمودين تتحول إلى عمود واحد على الهاتف.
